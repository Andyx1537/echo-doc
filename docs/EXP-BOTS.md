## 0. 目的

用一批**合成用户 bot**（不同消费观 × 操作习惯 × 情感画像）去"体验"我们的羁绊温度 & 爱心经济数值，产出**分群反馈**（留存 / 温度健康度 / 付费 / 红线风险），形成闭环：

```
调数值(§3.12参数) → 跑 bot 群体 → 看分群反馈 → 定位痛点/红线 → 再调 → 收敛
```

> 定位：这是**产品侧数值验证工具**（方向性、可复现），不是真实用户预测。用于把明显的"数值伤人 / 大面积挫败 / 增长感缺失"在上线前筛掉。

## 3. 模拟循环（每 bot · 每日）

沿用 §3.12 温度模型，外挂"行为 → 投入 → 满意/流失"层。90 天期程，起始温度 100。

1. **打开决策**：期望日投入按 `p_open` 折算（打开日挣满 `capFree`，订阅额外附赠按档叠加）。
2. **暖意投入 → 温度演化**：每宠暖意 = 日暖意 / 宠物数，代入
   `ΔT = −kDecay·(T−floor)·欠维系比 + healRate·(100−T)·盈余比`。
3. **满意度**：`sat = (T−floor)/(100−floor)`，叠加**新鲜衰减**（30 天后无解锁→ novelty 疲劳，按新鲜需求扣减）。
4. **流失风险（日 hazard）**：
   `hazard = baseChurn + k_low·sensitivity·max(0,(低温阈−T)/span) + k_nov·noveltyNeed·(疲劳期)`
   生存率 `S *= (1 − hazard)`；留存曲线 = S。
5. **付费贡献**：付费群按档在活跃期贡献；`LTV(90d) ≈ 月费 × (Σ S_d)/30`。

## 4. 反馈指标（内循环产出）

- **留存**：D1 / D7 / D30 / D60 / D90（分群 + 加权总盘）。
- **温度健康**：各群均温、低温占比、是否长期贴地板。
- **变现**：付费转化率、分档分布、分群 LTV、加权 ARPU。
- **数值痛点旗标**（自动判定）：
  - 白嫖多宠 → 大面积欠维系低温挫败；
  - 高级档过强 → 无成长感（秒满、失去养成）；
  - 回落过快 → 中频/低频群断崖流失。
- **🚨 红线告警**：C_grief 敏感群若均温贴近地板或 D30 骤跌 → **二次伤害/挫败流失风险**，触发数值回调（红线优先于留存/营收）。

## 5. 内循环的收敛判据（建议）

一组数值"可暂定"当且仅当：
1. **红线群体（C_grief）** 均温不长期贴地板、D30 留存不塌（安全第一）；
2. 白嫖单宠可稳住体验（`⌊capFree/c⌋ ≥ 1`）；
3. 付费群有**可感知增长/鲜活**（非秒满、非无区别）；
4. 大盘 D30 / ARPU 落在目标带内（目标带待定）。

## 6. 架子形态 & 可扩展性

- **v0.1 架子**：交互式**群体模拟画布** `canvases/echo-exp-bots.canvas.tsx` —— 内置 6 群体，数值滑杆（c / capFree / 基础 / 高级）联动，实时出分群留存/温度/营收/红线告警，闭合内循环。
- **可扩展挂点**：
  - 人口配比、群体参数外置可配；
  - 蒙特卡洛（引入随机与个体差异）替换期望值近似；
  - 接开发侧代码 harness（可跑 CI / 大批量 / 真链前压测）；
  - 接 LLM 定性 bot（`ILlmClient`）：让 bot 读到实际生成的回声文案，产出**定性体验反馈**（"这条太丧了""太单调了"），补充定量层。
  - 潮汐型、冷淡召回（O-P6）群体后续接入。

## 7. LLM 定性 Bot（内容体验反馈层）

定量层判断"数值是否伤人/是否留得住"；**定性层判断"文案本身好不好"**——让每个画像 bot 以自己的视角"读"实际生成的回声文案，产出主观评价，补充数值看不到的问题（太丧、太单调、太出戏、被催促感）。

### 7.1 画像嗓音（Voice Profile · PM 先定）

每个画像一份评审视角，决定它"在意什么"：

| 画像 | 嗓音/在意点 |
|---|---|
| 深度哀伤敏感 | 极在意情绪安全：怕被戳痛、怕罪疚暗示、怕"它以为你不来了"过头 |
| 温和怀念 | 要温暖真实、有它的性情；反感套路化、空洞煽情 |
| 收藏养成 | 要新鲜、有变化、有成长线索；最烦重复雷同 |
| 情感付费强依赖 | 要"独一份"的贴合感，值回票价；在意专属/细节 |
| 理性观察 | 挑剔真实性与逻辑；一出戏就想走 |

### 7.2 评审输入 / 输出

- **输入**：画像设定 + 当前温度档（60–75/75–90/90–100）+ **实际回声文案 payload**（往宠近况/动态）。
- **输出（结构化 JSON）**：
```json
{
  "personaId": "s2",
  "scores": {                    // 0–5，越高越好；warmthTone/intrusion 为"越低越好"
    "emotionalSafety": 5,        // 情绪安全（不伤人）
    "authenticity": 4,           // 真实立体
    "monotony": 1,               // 单调重复（越低越好）
    "surprise": 3,               // 惊喜/活泼
    "griefIntensity": 2,         // 丧感强度（适中最好，过高告警）
    "intrusion": 0,              // 被打扰/催促感（越低越好）
    "personaFit": 4              // 贴合宠物性情
  },
  "redFlag": false,              // 二次伤害/罪疚攻击风险
  "comment": "温暖有画面，但结尾略煽情，敏感用户可能被戳。"
}
```
- **红线聚合**：任一敏感画像 `redFlag=true` 或 `griefIntensity≥4` → 该文案模板打回。

### 7.3 接入方式（技术挂点）

- Harness 定义 `IBotReviewer { BotReview review(BotReviewContext ctx); }`。
- **默认 `HeuristicBotReviewer`**：规则/关键词启发式（无需 LLM，可跑 CI）。
- **`LlmBotReviewer`**：走 LLM。当前 `com.echo.infra.llm.ILlmClient` 仅有 `enrich(String)`；建议为其**新增 `String complete(String prompt)`**（Mock 兜底返回固定 JSON），`LlmBotReviewer` 拼 prompt→解析 JSON。真实供应商待 BE 选型，先 Mock。

## 8. 代码 Harness 架构规格（交后端落地）

**目标**：产品侧可跑的数值验证器——批量跑全画像库、输出分群报告（CSV/JSON）、CI 断言收敛判据（数值回归即红）、可选 LLM 定性层。

### 8.1 落点与依赖
- 位置：`echo-server` 新增包 `com.echo.harness`（纯内存，**不绑 WebSocket**）。
- 依赖：仅用现有 `gson`（读配置/写 JSON）；CSV 用纯 Java 输出，**不新增依赖**。
- 运行：`com.echo.harness.ExpBotsHarness#main`（参数：配置路径、输出目录）；CI 走 JUnit。

### 8.2 核心类型（建议）
| 类型 | 职责 |
|---|---|
| `NumericConfig`(record) | §3.12 参数：floor/c/capFree/basicGrant/premiumGrant/kDecay/healRate/horizon/K_LOW/K_NOV/fatigueDay |
| `BotPersona`(record) | 画像库项：id/name/weight/enabled/pOpen/pets/tier/sensitivity/novelty/baseChurn/lowTemp/grief/voiceProfile |
| `Population` | 从 JSON 资源 `resources/harness/populations/default.json` 加载（gson）、归一化权重 |
| `TemperatureModel` | `step(T, heartsPerPet, cfg)`——与 §3.12 公式一致 |
| `Simulator` | 期望值日循环（默认）：产出每群 survival[]/temp[]/avgTemp/d30/d60/d90/ltv |
| `MonteCarloSimulator` | 可选：带种子随机、N 次采样（扩展挂点，默认关闭） |
| `FlagEngine` | 依 §4/§5 生成痛点/红线旗标 |
| `AggregateReport` | 加权 D30/D90、ARPU、付费占比、红线风险群数、分群明细 |
| `ReportWriter` | 输出 `target/harness/report.json` + `segments.csv` |
| `IBotReviewer` / `HeuristicBotReviewer` / `LlmBotReviewer` | §7 定性层 |

### 8.3 CI 收敛断言（`ExpBotsHarnessTest`）
以 §3.12 v1-tentative 基线跑，断言（阈值可调，先宽后严）：
1. **红线**：所有 `grief=true` 画像 `avgTemp ≥ lowTemp` 且 `d30 ≥ 0.5`（安全第一）。
2. 白嫖单宠可稳：`⌊capFree/c⌋ ≥ 1`。
3. 付费群有增长感：premium 画像 `avgTemp < 99`（非秒满）且高于白嫖同画像。
4. 大盘：加权 `d30 ≥ 目标带下限`（目标带 TBD，先设 0.30 占位）。

> 数值一旦被改到伤害红线群体，CI 变红——这就是"内循环"的护栏。与交互画布 `canvases/echo-exp-bots.canvas.tsx`（可视化探索）共用同一套模型与配比。
