# Echo 中国大陆上线：三类合规与落地清单

> 适用：公开回忆瀑布（共鸣厅）+ 用户图文发布/回声互动 + 主题/推荐 + 订阅付费 + 可选 AI 图片整理/生成。
>
> 用法：**第一类找主管部门/服务商办，第二类公司内部定规则，第三类产品与技术做成真实能力。** 三类缺任意一类，都不应正式公开运营。
>
> **产品定位边界**：用户可为故去的亲友或宠物上传照片、故事与缅怀内容，并自主选择是否进入共鸣厅；这是 Echo 的一项情感承接能力和优势扩展面。Echo 对外定位仍是“回忆与共鸣社区”，**不自称、不宣传为网络墓园，也不提供殡葬、代祭或其他线下服务。**

## 一、需要对公正常申请、备案或取得确认的事项


| 项目                         | 首发是否必需                      | 去哪里/通过谁办                       | Echo 需提交或准备                                    | 完成标志                    | 负责人       |
| -------------------------- | --------------------------- | ------------------------------ | ---------------------------------------------- | ----------------------- | --------- |
| **运营公司主体**                 | 必需                          | 市场监管部门                         | 营业执照、法定代表人、经营范围；股权/外资情况                        | 可作为 App、支付、备案申请主体       | 法务/财务     |
| **域名实名与网站 ICP 备案**         | 必需（用中国大陆服务器时）               | 域名注册商 + 云/接入服务商 → 通信管理局        | 已实名域名、主体信息、负责人、服务器/IP、接入信息                     | 备案号可查，官网/H5/API 域名可合规解析 | 技术        |
| **App 备案**                 | 必需                          | 接入服务商或 App 分发平台 → 工信系统         | App 名称、包名、图标、版本、域名、主体、负责人、承诺书；如有前置审批一并提交       | 获 App 备案号，并在 App 内展示    | 技术+法务     |
| **经营性 ICP 许可证路径确认 / 申请**   | **首发收费时视为阻断项**              | 属地通信管理局；先由电信业务律师核验             | 收费模式、订阅权益、主体/股权、域名、服务器、业务方案、客服与信息安全能力          | 取得许可证，或取得书面专项意见确认无需办理   | 法务+财务     |
| **公安联网备案**                 | 必需                          | 属地公安网安部门                       | 运营单位、网络/服务器、负责人、网络安全措施等资料                      | 按属地要求完成备案；通常网络正式连接后及时办理 | 技术+安全     |
| **网络安全等级保护（等保）**           | 必需，具体等级待定                   | 属地公安 + 合规测评机构                  | 定级报告、系统边界、数据/网络拓扑、安全制度、整改证据、测评材料               | 定级备案完成；按最终等级完成测评/整改     | 安全+技术     |
| **算法备案/安全评估**              | 使用个性化推荐且具有相应舆论/社会动员属性时必需    | 国家/地方网信办系统                     | 算法机制、数据来源、人工干预、用户关闭入口、风险控制和安全评估                | 备案/评估结论完成；变更持续维护        | 技术+法务     |
| **生成式 AI / 深度合成安全评估及备案路径** | 对公众提供 AI 生成、特别是人像/声音处理时必需核验 | 网信部门；结合服务形态专项判断                | 模型/供应商、输入输出、训练数据、标识、投诉、风控、敏感人像同意机制             | 获得专项法律意见并完成适用的评估/备案     | AI 负责人+法务 |
| **应用商店上架审核**               | 必需                          | Apple App Store、各 Android 应用商店 | App 备案号、隐私政策 URL、主体资质、SDK/权限说明、支付、注销、测试账号、内容分级 | 审核通过且商店页面信息一致           | 运营+客户端    |


### 暂不申请，但功能一开必须先专项核验


| 功能                | 可能涉及              | 当前建议                                                             |
| ----------------- | ----------------- | ---------------------------------------------------------------- |
| 公开视频、直播、音频房       | 网络视听、版权及更严格内容管理   | **首发关闭**，单独立项、取得专项意见后再开                                          |
| 新闻聚合、热点资讯         | 互联网新闻信息服务         | 不做新闻业务，不用“热点/资讯”定位                                               |
| 数字出版物、电子书售卖       | 网络出版相关边界          | 不将普通用户回忆包装或售卖为数字出版物                                              |
| 故去亲友/宠物的线上缅怀功能    | 容易被误解为殡葬或“网络墓园”服务 | 可提供用户自主上传、回忆集、献花、回声与私密/公开可见控制；不提供线下殡葬/代祭交易，不使用“官方墓园”“线上陵园”等定位或宣传 |
| 境外云、境外 LLM/图片 API | 个人信息出境            | 首发只用中国境内合规资源；如确需出境，单独走评估/合同/同意路径                                 |

## 二、公司内部必须准备、通过并长期维护的规则类文件


| 规则/文件                 | 首发是否必需   | 必须写清楚的 Echo 规则                                         | Owner    |
| --------------------- | -------- | ------------------------------------------------------ | -------- |
| **用户服务协议**            | 必需       | 发布权利与责任、公开范围、作者控制、投诉与封禁、内容下架、付费/退款、争议处理                | 法务+产品    |
| **隐私政策**              | 必需       | 收什么、为什么收、存哪里、存多久、谁能访问、SDK/供应商、如何撤回/导出/注销；首次使用前显著展示     | 法务+技术    |
| **个人信息收集清单 / SDK 清单** | 必需       | 手机号、相册、相机、麦克风、位置、设备信息分别是否必要；每个 SDK 的公司、用途、数据类型、政策链接    | 技术+法务    |
| **敏感个人信息与第三方肖像规则**    | 必需       | 人脸、声音、未成年人、精确位置、逝者/在世第三人内容的处理边界；上传者权利承诺、单独同意、快速下架机制    | 法务+产品    |
| **AI 服务说明与授权规则**      | 有 AI 即必需 | AI 输入输出、是否训练、训练默认关闭、撤回后如何处理、供应商、AI 标识、禁止生成的内容          | AI+法务    |
| **社区公约**              | 必需       | Echo 倡导“真实记录、友好共鸣、不消费悲伤”；禁止网暴、诽谤、人肉、造谣、导流、诈骗、恶意营销、侵犯隐私 | 运营       |
| **内容审核与处置规范**         | 必需       | 审核分级、机审/人审、拦截词、图片风险、下架/限流/封禁标准、复审、证据保留和时限              | 运营+安全    |
| **回声/评论治理规则**         | 必需       | 作者可关闭互动；回声类型与字数；禁止搭讪、恶意揣测逝者、攻击、引流；异常涌入的“降温”流程          | 运营+产品    |
| **举报、侵权投诉与申诉规则**      | 必需       | 入口、所需材料、紧急下架、处理时限、进度通知、复核人、肖像/隐私优先级                    | 运营+法务    |
| **未成年人保护规则**          | 必需       | 首发 18+ 发布；疑似未成年人转人工；禁陌生人私信；年龄识别、家长/监护人投诉处理             | 运营+产品    |
| **订阅、自动续费、退款规则**      | 收费即必需    | 价格/周期/权益、自动续费显著提醒与便捷取消、退款、到期后内容是否可见/可导出、客服 SLA         | 运营+财务+法务 |
| **数据分类分级、保留与安全事件制度**  | 必需       | 哪些是敏感数据、访问审批、日志、备份、最短必要保存、导出、泄漏响应、供应商管理                | 安全+技术    |
| **运营内容与营销素材规范**       | 必需       | 种子内容版权/肖像授权、AI 标识、广告审查、禁止直接搬运抖音/小红书内容、悲伤内容不做刺激性投放      | 运营+法务    |
| **推荐/精选运营规则**         | 有瀑布即必需   | 编辑精选标准、主题占比、负反馈、停止推荐、不得按悲伤或争议放大内容；个性化推荐另按算法规则维护        | 运营+产品    |

## 上线总门禁：负责人只需看这一页

### 可以进入邀请制灰度的条件

- App 备案已提交并已确认灰度策略符合接入商/应用商店要求；正式大规模公开前拿到备案号。
- 主体、域名、云资源、收费所需 ICP 许可证路径已由法务书面确认。
- 用户协议、隐私政策、社区公约、审核/投诉/订阅规则已批准并在 App 可访问。
- 公开—审核—瀑布—回声—举报—下架—申诉全链路实测通过。
- “仅自己 / 链接 / 公开”三档可见范围与一键安静可用。
- 审核人员、客服、法务升级联系人及 15 分钟高风险响应机制已排班。
- 种子内容 100% 有来源、授权、AI 标识与下架联系人台账。
- 数据、权限、SDK、备份、日志、删除/导出/注销已完成安全验收。

### 可以正式开放下载和收费的额外条件

- App 备案号已经取得并在 App 展示；各应用商店资料与实际功能一致。
- 公安联网备案、等保定级/测评工作按属地要求已完成或取得可上线的正式节点结论。
- 198/998 收费前，经营性 ICP 许可证的办理/不适用结论已书面闭环。
- 如开启个性化推荐或公开 AI 服务，算法/AI 的评估、备案及标识义务已闭环。
- 订阅取消、退款、到期保存与导出流程已用真实订单全链路验收。
