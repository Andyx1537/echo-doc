## 1. 已达成的战略共识

### 1.1 产品是什么

Echo 是一个 **陪伴记忆的数字纪念与共鸣空间**：

- 用户可以为宠物留下日常、成长、告别与向前的记忆；
- 用户可以主动将一段回忆发布到共鸣厅；
- 其他人可以在作者许可的范围内留下回声；
- 回声让作者感到“这段陪伴被合适地接住”，也让读者生出自己的记忆；
- 长期从宠物扩展到“重要的人 / 家庭记忆 / 共同记忆网络”。

它不是：AI 复活工具、单一哀伤社区、宠物内容娱乐平台、依靠热度竞争的社交产品。

### 1.2 一句话市场主张

> 它留下的，不止一张照片。把一件只有你记得的小事，留在这里。

### 1.3 运营北极星

> **被接住的发布率**：一张发布到共鸣厅的回忆，在 7 天内获得至少一种合规回声，且作者未撤回或关闭互动的比例。

这比 DAU、浏览量、互动数更能衡量生态是否健康。

## 2. 用户角色与首页共识

| 用户角色 | 为什么进入 | 共鸣厅里的位置 | 运营目标 |
|---|---|---|---|
| 留下者 | 想记录、纪念、整理一段陪伴 | 发布者、回声接收者 | 建立首次发布与持续创作 |
| 共鸣者 | 被他人具体记忆触动 | 留下恰当回声 | 从浏览转向真实共鸣 |
| 漫游者 | 想看别人如何爱、如何记得 | 主题浏览、收藏、轻回应 | 从观光转向理解与未来发布 |

### 首页路由

- 新游客**默认进入共鸣厅瀑布**，不直接强制进入建档；
- 共鸣厅既是发布场，也是观光与理解产品的入口；
- 用户从“我也想为 ta 留一处”进入回忆集录入；
- 用户进入录入页后，视为已主动选择开始建立回忆集，不再制造额外的隐私/情绪阻碍；
- 已有回忆集的用户默认进入“我的它”或上次停留页，共鸣厅保持一级入口。

## 3. 内容与发布共识

### 3.1 内容的完整情绪曲线

共鸣厅不应被告别叙事占满。

> ⚠️ **2026-08-25 裁定回改（`DECISIONS.md §G⁗⁗‴ OPS1`）**：🔴 **原「建议占比 40/25/25/10」已删除，不再预先规定各类内容的占比。**
> 下表四类**保留为观测维度**（`OPS1` 选定的唯一一套），内容分布**只作为观察指标记录与复盘，不作为供给目标下达、不作为考核项**。

| 观测类目 | 运营意义 |
|---|---|
| 正在发生的陪伴 | 让用户理解：日常本身值得留下 |
| 长大与变化 | 让关系拥有时间感，不只靠情绪强度 |
| 仍被记得的陪伴 | 承接郑重纪念与被理解需求 |
| 向前的回声 | 表达延续，而非将用户困在失去里 |

情绪曲线是否完整，靠**选题与审稿**把关；发现某一类长期缺失或过载，是复盘的输入，**不是要去补齐的指标**。

### 3.2 发布原则

- 建档、私密记录与发布是不同动作；
- 发布的最小单位是一张回忆卡，不是整个个人档案；
- 每次发布由用户选择：**共鸣厅 / 持链接 / 留在自己的回忆集**；
- 系统可以记住上次选择，但不能默默替用户公开；
- 作者可编辑、撤回、暂停互动，并决定可接收的回声范围；
- 运营审核与推荐确保内容质量，但不把“更痛、更煽情”作为分发标准。

## 4. 共鸣与回声共识

### 4.1 回声的定义

回声来自 **他人已共享的回忆 + 用户产生的共鸣**。

它不是平台替宠物发言，也不应使用“它在等你”“它今天怎样了”作为召回或留存逻辑。~~P0 中 LLM 可用于审核辅助、主题标签和风险提示；不替用户回应、不替宠物说话。~~

> ⚠️ **2026-08-25 回改**：🔴 **「P0 中 LLM 不替宠物说话」已被推翻。** 现行口径：**AI 宠物近况保留 P0，且可用它的口吻**，但更克制——**明确「回忆 / 温柔想象」框、降低拟真、降低频率**，🔴 **绝不称「它还活着 / 在等你」**，且必须带「非事实 / 基于你记忆的温柔想象」的**明确诚实标识**。
>
> **依据**：`DECISIONS.md §G''' CR1`（2026-07-28 裁定 = **C 折中并存**，明确**不采纳**「移除 AI 代宠物近况出 P0」；回声=双层并存，①AI 宠物近况为私域核心、保留 P0，②共鸣回响为社交层）+ `CR2`（诚实标识 + 弱化强缺席暗示）+ `§G⁗′ CM2`（2026-08-04 就「以它口吻说话」的边界再次裁定为**折中**：保留 P0、可用它口吻、但更克制）。
>
> **本节仍然成立、未被推翻的部分**（这几条正是 `CR2`/`CM2` 采纳运营顾虑的落点，不要连带放松）：
> - 🔴 **不用「它在等你」「它今天怎样了」作召回或留存逻辑** —— 与 `CR2`「弱化强缺席暗示、不施压回访」、`DP2`「不催回访」同向；
> - 🔴 **不替用户回应** —— 未被推翻，AI 只生成「它的近况」，不代替用户表达共鸣；
> - **回声的社交层定义**（他人已共享的回忆 + 用户产生的共鸣）继续成立，它是 `CR1` 双层里的第②层，与第①层 AI 近况**并存而非互斥**；
> - LLM 用于审核辅助、主题标签、风险提示继续成立。
>
> 变的只有一句：**LLM 在 P0 可以用它的口吻讲近况**（带标识、更克制），而不是仅限审核辅助类用途。

### 4.2 回声的运营原则

- “记得”是最基础的共鸣标识，不等于点赞；
- 回声必须有不同距离：静默靠近、感受联想、郑重回应、唤起自己的记忆、持续主题关系、轻支持；
- 作者决定一张卡允许哪些互动；
- 共鸣者不因表达能力不足而被排除，允许不写长话也能留下真实回应；
- 不显示公开互动数、热榜、停留榜、粉丝关系或竞争性排名；
- “留心意”先验证免费表达价值，付费后置，且不能购买曝光、温度、互动优先级或作者分成。

具体回声图谱见 `PRD-RESONANCE-INTERACTION-PALETTE.md`，由产品与设计择优拆分版本。

## 5. 共鸣厅的运营策略

### 5.1 供给结构

首页内容由三部分组成：

1. **编辑精选**：真实、具体、有长期价值的记忆，用于定调；
2. **共鸣相关**：与用户主动兴趣、停留、记得、主题相关的内容；
3. **新回忆**：审核通过的新发布，确保新作者得到被看见的机会。

运营推荐标准：稀罕而具体、陌生人容易进入、情绪有余地、表达真实。

不推荐：极端悲伤钩子、攻击/自责、隐私未处理内容、导流营销、求打赏内容。

### 5.2 种子期运营方式

- 首批招募 **30–50 位**愿意共创且充分知情的用户（⚠️ **2026-08-25 `OPS2`**：种子规模统一以**作者数**计，单位是「位」，**篇数不限**）；
- 运营以“回忆采访者”身份协助，不代写煽情故事；
- ~~每位用户产出一张作者确认过的回忆卡；~~ → **每位用户至少产出一张作者确认过的回忆卡，产出几张不作规定**（`OPS2`：篇数不是指标）；
- 建立《它总会这样》《窗边 / 门口 / 雨天》《后来我还会这样做》等栏目；
- 运营每周复盘回声质量、作者续发、撤回/举报，而不是追逐浏览量。

## 6. 商业化共识

### 6.1 收入来源

| 阶段 | 用户购买的真实价值 | 方向 |
|---|---|---|
| P0 | 验证纪念与共鸣价值，同时验证长期服务订阅 | 免费完整纪念/共鸣 + 订阅体验；归档、呈现与年度回顾 |
| P1 | 保存与呈现 | 高级保存、电子/实体纪念册、主题装帧、私密家庭页 |
| P2 | 共同传承 | 家庭共写、多人授权、长期托管、代际故事册 |

### 6.2 不可触碰的边界

- 不卖共鸣厅曝光、热榜、置顶；
- 不卖被记得次数、暖光、脚印和互动权；
- 不用敏感记忆/哀伤文本做定向营销；
- 不做作者从陌生人心意中分成的打赏模式；
- 不让广告侵入情感内容场景。

## 7. 运营向产品提出的必要能力

产品、设计、研发可自行决定实现方案，但 P0 市场验证至少需要：

1. 新游客进入共鸣厅而非强制建档；
2. 用户可创建、私存、主动发布和撤回一张回忆卡；
3. 发布时用户可选择可见范围与回声接受范围；
4. 支持基础且非竞争性的回声表达，并由作者控制；
5. 运营审核、精选、主题标签、低风险推荐能力；
6. 用户可报告、屏蔽、暂停互动；
7. 运营后台可观察发布、被接住、续发、撤回、举报等健康指标；
8. 模型/演示不夸大能力：真实模型测试与 mock 诚实表达为种子内测门禁。
