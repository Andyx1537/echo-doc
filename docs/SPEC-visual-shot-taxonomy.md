> **本文解决的问题**：出图一直是「每次现编 prompt」，结果是同一批人写出同一种画面——斑驳老墙、旧木家具、昏黄室内反复出现，43 张看上去像同一个房间的 43 个角落。本文把出图从「现编」改成**查表组合**：六个维度各自封闭枚举，题材分层可枚举，配额可核对，prompt 可拼装。

## 1. 出图参数六维模型

六个维度分别是**焦距、光圈、时间（时段 + 年代）、视野、主体内容、预设题材内容**，另加一条正交的**地域**轴。每个维度都是**封闭枚举**——不在枚举里的取值不许用；每个取值都带**配额**，配额以 43 张为基数。

机器可读版本在 `docs/assets/shot-taxonomy.json`，本文与该文件是同一份数据的两种呈现，改一处必须改另一处。

### 1.1 焦距

| 档 | code | 画面效果 | 适用题材 | 配额（/43） |
|---|---|---|---|---|
| 28mm | `F28` | 纵深强、边缘畸变、容易把主体推远 | 操场、大礼堂、春运候车、露天电影、秋收晒谷场、筒子楼走廊 | **1–3** |
| 35mm | `F35` | 交代地点的同时主体还在中景，畸变可控 | 胡同、弄堂、骑楼、夜市、工人新村、雪天、轮渡 | **5–8** |
| 38mm | `F38` | 接近人眼但带出环境关系 | 通用 | 3–5 |
| 40mm | `F40` | 环境与主体权重接近 1:1 | 通用 | 5–7 |
| 44mm | `F44` | 人眼视角，主体确定、环境完整 | 通用（**主力**） | **10–12** |
| 50mm | `F50` | 轻压缩，主体更实、背景更整齐 | 通用（**主力**） | **9–12** |
| 60mm | `F60` | 压掉杂乱背景，但极易滑向特写 | 仅当背景无法整理时 | 0–4 |
| ~~85mm~~ | 废除 | 产品图观感 | — | 0 |
| ~~24mm~~ | 废除 | 超广作为默认值已否 | — | 0 |

**广角怎么合法**——这是本次要回答的问题。用户要「广角也要带点」，但不能回到无约束状态，所以采用三重限制：

1. **题材白名单**：只有需要交代「空间本身有多大」的题材才允许广角——`campus`（操场）、`transit`（绿皮火车、公交、春运、轮渡）、`factory`（车间、工人新村、大礼堂、食堂）、`leisure`（溜冰场、露天电影）、`season`（夏夜、雪天、秋收、年节、河堤）、`home`（筒子楼、家属院）、`street`（胡同、弄堂、骑楼、夜市）。**家庭室内小空间、宠物、静物类题材一律不允许广角**——那是畸变而不是视角。
2. **配额**：`F28 + F35` 合计 **8–10 张（19%–23%）**，其中 **`F28` ≤3 张**。
3. **`F28` 三条护栏**（缺一条即判不合格）：
   - 画面近处必须有可辨识**前景锚点**（栏杆 / 课桌角 / 车把 / 雪堆 / 板凳），否则纵深会变成空洞；
   - 主体像素高度 **≥ 画面高度的 1/5**，否则就踩了「主体变成远处小点」的红线；
   - 人脸不得靠近画框边缘——广角边缘畸变会把脸拉变形，与 B 档「柔化不可辨识」是两回事，一个是温柔一个是失真。

### 1.2 光圈

光圈这一维不是审美选择，它直接绑死**「背景要可读」这条构图红线**。定义清楚什么叫可读：

> **背景可读 = 背景中至少有一个次级信息保持可辨形状**（黑板轮廓 / 晾衣绳 / 店招的形状但无字 / 远处人影 / 窗格）。糊成一团色块即不合格。

| 档 | code | 背景可读性 | 什么场景才允许 | 配额 |
|---|---|---|---|---|
| f/2.0 | `A20` | 弱 | **仅两种情况**：① 夜晚/室内弱光且背景本身是点光源散景、不承载叙事信息；② 主体与背景距离 ≤3m，虚化不足以抹掉形状 | 0–3 |
| f/2.8 | `A28` | 中 | 室内人像主力；背景须保留可辨轮廓（门框/柜面/窗格） | 6–10 |
| f/4 | `A40` | 好 | 通用主力，任何题材 | **12–16** |
| f/5.6 | `A56` | 很好 | 多人叙事、环境关系需要同时清楚 | **10–14** |
| f/8 | `A80` | 全清 | 大场面、纵深空景、群像 | 2–6 |

判定口径：**开大光圈是需要理由的，收小光圈不需要**。写规划表时 `A20`/`A28` 必须在「备注」列写明属于上述哪一种允许情形；写不出来就降到 `A40`。

### 1.3 时间

时间拆成两个子维度：**时段**（一天中的光）与**年代**（场景道具与色调世代）。

#### 1.3.1 时段

| 档 | code | 光的特征 | 配额 |
|---|---|---|---|
| 清晨 | `T_DAWN` | 低色温、薄雾、长影、空气感 | 3–5 |
| 上午 | `T_MORN` | 斜射硬光但不刺眼，阴影有方向 | 5–8 |
| 正午 | `T_NOON` | 顶光、短影、对比高，需柔化 | 1–3 |
| 午后 | `T_AFT` | 暖白、窗光成块、尘埃可见 | 7–10 |
| 黄昏 | `T_DUSK` | 低角度金色、剪影倾向 | 5–7 |
| 蓝调 | `T_BLUE` | 天空冷蓝 + 室内暖灯的双色温 | 4–6 |
| 夜晚 | `T_NIGHT` | 点光源为主，须保留暗部层次 | 4–6 |
| 室内人工光 | `T_INDOOR` | 白炽/日光灯，色温单一（可与上列叠加） | 3–5 |

**明暗配额**：清晨+上午+正午+午后合计 **≥18 张（≥42%）**；黄昏+蓝调+夜晚合计 **≤18 张**。这条是对「全是昏黄」最直接的矫正——当前图库的明亮时段严重不足（数据见 `seed-cover-shot-plan.md §3`）。

#### 1.3.2 年代

年代轴与 `ART.md §3.1` 的 E1–E5 对齐，**同一套代码，不另造一套**。年代不是滤镜，是**器物世代**：写 prompt 时必须落到具体道具，否则一定出「年代含混」。

| code | 年代 | 标志性道具（prompt 里挑 3–4 件） | 色调特征 | 配额 |
|---|---|---|---|---|
| `E1` | 80s | 搪瓷盆/搪瓷缸、竹壳暖水瓶、二八自行车、绿漆墙裙、白炽灯泡、水泥地、木格窗、铝饭盒 | 偏黄绿、低对比、颗粒明显 | 4–6 |
| `E2` | 90s | CRT 电视/显示器、脚踏缝纫机、蜂窝煤炉、彩条塑料布、卷闸门、马赛克瓷砖、折叠木椅、台式风扇 | 暖黄 + 青绿，中低饱和 | **10–12** |
| `E3` | 00s | 网吧机箱、复读机、铝合金推拉窗、马赛克外墙小楼、面包车、塑料凉椅、挂历、燃气热水器 | 偏冷的日光 + 荧光灯白 | **10–12** |
| `E4` | 10s | 贴膜手机、快递纸箱、LED 灯带、不锈钢晾衣架、电动车、塑钢窗 | 干净中性、轻微冷调 | 6–8 |
| `E5` | 当代 | 滚筒洗衣机、扫地机器人、外卖保温箱、玻璃幕墙倒影、共享单车 | 明亮、低对比、接近直出 | 6–8 |

主力压在 E2–E3（目标用户的集体记忆峰值），但 **E4+E5 必须占到 12–16 张**——否则整个共鸣厅像个博物馆，当代用户找不到「我也有」的入口，而这恰恰是种子内容公式里「让人停下」的前提。

**反模式：年代含混**。同一画面混入跨代器物（90s 场景里出现智能手机、E1 场景出现塑钢窗）即判不合格。这不是挑剔——年代含混的画面读不出「哪一年」，也就读不出「那时候」。

### 1.4 视野（景别）

| 档 | code | 定义 | 配额 |
|---|---|---|---|
| 大远景 | `FR1` | 城市/雪原/操场全貌，人物为剪影尺度 | 0–3 |
| 远景 | `FR2` | 完整场景 + 小尺度但可辨的人物 | 4–7 |
| 全景 | `FR3` | 主体全身 + 完整环境 | **12–16（主力）** |
| 中景 | `FR4` | 腰以上，环境仍可读 | **10–14（主力）** |
| 中近景 | `FR5` | 胸以上或侧背影，背景须保留形状 | 0–6 |
| ~~特写~~ | `FR6` | **禁用** —— 踩「物体大特写/人物特写」红线 | 0 |
| ~~微距~~ | `FR7` | **禁用** —— 踩「不要微距」红线 | 0 |

三条护栏：

- `FR1`/`FR2` 下**主体像素高度 ≥ 画面高度 1/5**，否则退化为「远处的小点」；
- **前景人物全身在框内**。坐姿半身（如吃面、伏案）是唯一例外，须在规划表显式标注「例外：坐姿」，不允许默认；
- **不要「特别远的局部」**——既退得很远又只拍场景的一角，这是同时踩两条红线，最常见的表现是「远处一堵墙的一部分」。

### 1.5 主体内容

| 档 | code | 配额 | 说明 |
|---|---|---|---|
| 人 | `SB1` | 16–20 | |
| 动物 | `SB2` | 5–8 | |
| 人+动物 | `SB3` | 4–7 | |
| 纯环境 | `SB4` | 12–14 | **必须带缺席锚点** |

**活物 30 张（70%） / 空景 13 张（30%）**，对应已拍板的 7:3。

**人脸 B 档**（复述，因为这是每张有人的图都要检查的）：侧脸 / 低头 / 发丝遮挡，柔化到不可辨识；全身在框内不被裁切。禁止可辨识的真实人脸、正面直视镜头、证件照式头像。

**缺席锚点**——空景之所以不是空荡，靠的是一个「人刚刚还在」的痕迹。每张 `SB4` 必须在规划表里填一个：

- 还在轻晃的秋千 / 门帘
- 没收的碗筷、还剩半碗的面
- 门开着一条缝，光从里面漏出来
- 拖鞋摆歪、一只朝里一只朝外
- 灯还亮着但椅子空着
- 水盆里刚落下的涟漪
- 刚被压过的草地 / 雪上单排脚印
- 晾着的一件小号衣服

没有锚点的空景就是空房间照片，它不产生「我也记得」，只产生划走。

### 1.6 地域

地域是正交轴，决定建筑、植被、气候、光线、色调。**不写地域的 prompt 一定出「无法判断哪里」的通用亚洲老街**，这是当前图库最隐蔽的同质化来源。

|---|---|---|---|---|---|---|---|

| `R_JIANGNAN` | 江南 | 白墙黛瓦、石库门、青石板、天井 | 香樟、爬山虎 | 梅雨、潮湿、苔痕 | 漫射柔光，少硬阴影 | 青灰、米白、墨绿 | 7–9 |
| `R_LINGNAN` | 岭南 | 骑楼廊柱、趟栊门、防盗网、卷闸 | 榕树气根、芭蕉、三角梅 | 湿热、雨后蒸腾 | 顶光强、廊下大片阴影 | 偏绿的暖调、灰米色 | 5–6 |

## 2. 怀旧主题集枚举

**8 条题材线 · 49 条具体题材**。43 张封面从这 49 条里选，天然留出 6 条的富余，避免「不够用只好重复」。

每条题材给出：典型场景、标志性道具、适配年代、适配地域、推荐焦段/光圈/时段、**是否允许广角**、**是否适合作为空景表达缺席**。完整字段见 `shot-taxonomy.json`，本节给可读版。

## 3. 关键词组件库（prompt 构件化）

出图不再现编 prompt，而是**固定风格块 + 槽位填充**。槽位的值全部来自 §1、§2 的枚举，所以 prompt 变成查表组合，且天然可被脚本生成与校验。

### 3.1 固定风格块 `STYLE_BASE`（每次原样带上，不改动）

```text
photorealistic documentary photograph, muted low-saturation film color,
soft natural contrast, fine grain, gentle highlight rolloff,
natural skin and material tones;
vertical 2:3 framing;
background stays legible with at least one discernible secondary element;
no readable text of any kind, no signage lettering, no brand, no logo, no watermark;
any person shown from behind or in profile or head lowered,
face softened and unidentifiable,
whole body inside the frame and never cut by the frame edge
```

### 3.2 槽位

| 槽位 | 取值来源 |
|---|---|
| `{THEME_SCENE}` | §2 题材的英文场景描述 |
| `{REGION_LOOK}` | §1.6 地域的 建筑 + 植被 + 色板 |
| `{ERA_PROPS}` | §1.3.2 年代道具中挑 3–4 件 |
| `{FOCAL}` | §1.1 焦距的 mm 值 |
| `{APERTURE}` | §1.2 光圈的 f 值 |
| `{FRAMING_EN}` | extreme wide shot / wide shot / full shot / medium shot / medium close shot |
| `{DAYPART_LIGHT}` | §1.3.1 时段的光特征 |
| `{SUBJECT_CLAUSE}` | a person / a cat / a dog / a person with a dog / no living being present |
| `{ABSENCE_CLAUSE}` | 主体为 `SB4` 时**必填**，取自 §1.5 缺席锚点 |

### 3.3 完整模板

```text
{THEME_SCENE}, {REGION_LOOK}, {ERA_PROPS},
shot on {FOCAL}mm lens at {APERTURE}, {FRAMING_EN}, {DAYPART_LIGHT},
{SUBJECT_CLAUSE}{ABSENCE_CLAUSE}.
{STYLE_BASE}
```

### 3.4 负向词块 `NEGATIVE_BASE`（每次原样带上）

```text
text, letters, chinese characters, handwriting, signage, shop sign, logo, brand,
watermark, subtitles, captions;
close-up, extreme close-up, macro, product shot, hero still life object,
isolated object on table;
HDR, oversaturated, vivid colors, neon oversaturation, heavy clarity,
crushed blacks, teal and orange grading;
identifiable face, frontal portrait, direct eye contact, headshot;
person cropped by frame edge, subject reduced to a tiny distant dot,
distant fragment of a scene;
fully blurred unreadable background, bokeh wash-out;
era mismatch props;
mottled peeling damp wall as default backdrop, generic aged wood tabletop,
dim yellow tungsten interior as default
```

最后一行是本次新增的**反同质化负向词**——把「斑驳墙 / 旧木桌面 / 昏黄室内」直接写进禁止项，除非题材枚举里明确要求它们（如 `home-tongzilou`、`street-longtang`）。这条不加，模型会把它们当成「怀旧」的默认答案，这正是当前 43 张长得像同一个房间的技术原因。

## 4. 配额与打散规则

配额以 **43 张**为基数。所有数字可逐条核对，核对结果回填 `seed-cover-shot-plan.md`。

### 4.1 维度配额汇总

| 维度 | 硬性数字 |
|---|---|
| **广角** | `F28`+`F35` **8–10 张**，其中 `F28` **≤3 张** |
| **主力焦段** | `F44`+`F50` **20–24 张** |
| **明亮时段** | 清晨+上午+正午+午后 **≥18 张（≥42%）** |
| **暗调时段** | 黄昏+蓝调+夜晚 **≤18 张** |
| **年代** | E1 4–6 · E2 10–12 · E3 10–12 · E4 6–8 · E5 6–8；**E4+E5 合计 12–16 张** |
| **地域** | 北方 8–10 · 江南 7–9 · 岭南 5–6 · 西南 4–5 · 沿海 3–4 · 县城 6–8 · 大城市 5–7 |
| **主体** | 活物 **30 张（70%）** / 空景 **13 张（30%）** |
| **景别** | 全景 12–16 · 中景 10–14 为主力；大远景 ≤3；中近景 ≤6；**特写与微距 = 0** |
| **光圈** | f/4 12–16 · f/5.6 10–14 为主力；f/2.0 ≤3 |

### 4.2 质感配额（反同质化的核心）

| 质感标签 | 上/下限 | 占比 |
|---|---|---|
| `TX_MOTTLED` 斑驳/剥落/做旧墙面为主导 | **≤11 张** | ≤25% |
| `TX_OLDWOOD` 旧木家具为视觉主体 | **≤8 张** | ≤19% |
| `TX_DIMINDOOR` 昏黄室内为主调 | **≤9 张** | ≤21% |
| `TX_WETREFLECT` 潮湿反光/雨夜 | **≤6 张** | ≤14% |
| `TX_CLEANBRIGHT` 明亮/干净/当代质感 | **≥13 张** | ≥30% |
| `TX_OUTDOOR` 户外自然光为主 | **≥17 张** | ≥40% |

### 4.3 打散规则

| # | 规则 | 为什么 |
|---|---|---|
| DR-1 | 单条**题材线**在 43 张里 ≤8 张（≤19%） | 没有这条，一条线能吃掉半个图库 |
| DR-2 | 单条**具体题材** ≤2 张 | 同题材第 3 张必然重复构图 |
| DR-3 | 同一「题材线 × 年代 × 时段」三元组 ≤2 张 | 三者都相同的两张图，视觉上就是同一张 |
| DR-4 | 同一分类**封面池内相邻序号**两张不得同题材线 | 封面池按 `index % pool.length` 轮转（`mock.ts`），相邻序号会在瀑布流里同屏出现 |
| DR-5 | `TX_MOTTLED` + `TX_OLDWOOD` + `TX_DIMINDOOR` 去重后合计 **≤18 张（≤42%）** | 这三件套就是用户说的「斑驳」 |
| DR-6 | 每个分类的封面池内**至少 1 张** `TX_CLEANBRIGHT` | 避免某个栏目整体发暗 |
| DR-7 | 广角必须满足 §1.1 的题材白名单 + `F28` 三条护栏 | 「带点广角」不等于「随便广角」 |
| DR-8 | 每张空景必须在规划表填一个**缺席锚点** | 填不出来的空景就是空房间照片 |

### 4.4 校验方式

`shot-taxonomy.json` 里所有配额都是结构化字段，规划表填完后可用一段脚本比对。建议的校验产出：**每条配额一行「实际 / 目标 / 是否达标」**，不达标的直接给出需要重做的张数。这一步不做，配额就只是文档里的数字。

## 5. 合规

| 项 | 要求 |
|---|---|
| 可读文字 | 画面内**零可读文字**，含招牌字、粉笔字、春联、幕布字幕、街机屏幕文字 |
| 品牌 | 无品牌、无 logo、无水印 |
| 人脸 | B 档：侧脸/低头/发丝遮挡，柔化不可辨识；**禁止可辨识的真实人脸** |
| AI 标识 | **显式标识**由前端卡片左下角角标承担，**不烧进图片**；**隐式标识**（元数据水印）按 `SPEC-trust-and-compliance §CM-G2 / §CM-G0S S-8` 在入库管线写入，且缩略图与呈现图**派生后须重新写入** |
| 入库确认 | 按 `ASSETS.md §5`，逐条确认「无可识别人脸、无可读文字、无商标」，并重建 `MANIFEST.json` |

**天然带字的五条题材**必须逐张确认：`campus-blackboard`、`street-nightmarket`、`leisure-arcade`、`leisure-openair`、`season-newyear`。处理手法只有四种——纯色块 / 背面角度 / 深度虚化 / 过曝白。

## 6. 使用方式

1. **出图前**：在 `seed-cover-shot-plan.md` 的规划表里先填满六维 + 地域，确认不违反 §4 配额与打散规则；
2. **拼 prompt**：按 §3 模板填槽位，带上 `STYLE_BASE` 与 `NEGATIVE_BASE`；
3. **出图后**：把实际参数回填规划表（生成参数与实际观感可能有偏差，以实际观感为准）；
4. **入库**：按 `ASSETS.md §5` 压缩、重建清单；
5. **上线后**：回填热度列（见 `seed-cover-shot-plan.md §4`）；
6. **定期复盘**：按热度与配额达标情况调整题材权重，下一批据此选题。
