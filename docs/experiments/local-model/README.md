## 资料与证据

- 公共 Git：本目录下 SETUP.md、MODEL-MANIFEST.md、schemas/、prompts/、fixtures/、reports/。
- fixtures 只收虚构资料和预期答案，不含真实手机号、用户聊天、照片或生产数据。
- 原始结果存本地 runs，每次独立编号，不覆盖；公共报告保存脱敏案例和必要证据，不提交权重及完整日志。
- 记录运行编号、样本/提示词/配置版本、模型摘要、工具版本、原始输出、校验、耗时、内存、失败与重试。冷启动和热运行分开。
- 模型没有文件、命令、网络工具权限；测试资料不是训练数据，不自动形成长期记忆。

## 测试与退出条件

先3组小样：完整资料、缺失资料、纠正/多宠边界；通过记录流程后扩为30组：完整10、缺失8、矛盾纠正6、边界6。保留10组不用于调提示词；其中10组重复3次看稳定性。

候选门槛：事实编造、主体混淆、擅自暗示死亡均记关键失败；结构通过率与明确信息提取准确率目标各≥95%，同时给实际分子分母。小样不作统计性通过结论。任何错误保留，不只选择最好结果。
