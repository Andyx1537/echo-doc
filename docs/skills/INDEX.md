# 回声项目共享 Skills

本目录是回声项目跨产品、设计、前端、后端、QA 与运营共享的 skill 契约库，定位类似公共 `proto`：统一定义工作方法、输入输出、交付标准和验证纪律。

## 使用规则

1. 本目录中的版本是唯一真源；个人目录中的 skill 只是安装副本。
2. 修改必须使用独立分支，并说明旧规则、当前规则、新规则及影响范围。
3. 修改后必须校验 skill 结构，提交 Git 并推送远端；远端未存在相同提交，不得称为已备案。
4. 专业人员获取或更新 skill 时，从本目录复制完整 skill 文件夹，不得只摘录其中一段形成私有变体。
5. 如果确需专业变体，应新增独立 skill 或引用文件，并明确继承关系，不能静默改写公共规则。
6. 本地安装副本与仓库不一致时，以仓库已合并版本为准；未合并分支仅供该变更验证。

## 当前目录

| Skill | 作用 | 权威入口 |
|---|---|---|
| `development-readiness` | 产品与技术修改前的基线比对、前后端同步、验收、分支和交付标准 | `development-readiness/SKILL.md` |

## 分发结构

```text
docs/skills/
├── INDEX.md
└── development-readiness/
    ├── SKILL.md
    └── agents/

```

同步到个人环境时，目标目录保持相同文件结构。仓库提交号应记录在交接信息中，以便确认每个人使用的是哪一版。
