## Gate B · 环境与数据

- [ ] 测试数据库可重置、可查询，并能验证唯一约束和事务回滚。
- [ ] 服务可重启或多实例切换，重启不会清除会话。
- [ ] 对象存储测试桶、资源引用探针、额度记录和孤儿队列可查询。

- [ ] 机器夹具 `fixtures/onboarding-v1.json` 校验通过。
- [ ] 清晰单宠、模糊、多宠、人宠同框、不同宠和视频媒体夹具具有固定校验和。
- [ ] 测试账号至少包含两个匿名账号、一个可 `bind_current` 账号、一个可 `switch_existing` 的已有账号。

## Gate C · 契约烟测

- [ ] 所有写请求要求 `Idempotency-Key` 和 `expectedSessionVersion`。
- [ ] 全部错误使用 `{code,msg,detail,data}`，前端不解析 `msg` 判定状态。
- [ ] Q1～Q4 只接受冻结选项码和基数；Q3 短文本门控正确。
- [ ] 匿名专用上传可用，而匿名全局 `/upload` 仍被拒绝。
- [ ] consent 可授予/撤回，版本可用于 confirm CAS。
- [ ] 状态和 `allowedActions` 由后端返回，前端不自行推进。
- [ ] 新客户端不调用旧一次性 Onboarding 端点。
