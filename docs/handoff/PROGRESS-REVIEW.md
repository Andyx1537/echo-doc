## 当前分工

- 实现与验收方：继续推进当前阶段 TODO，维护原阶段账本、提交与验收证据；当前由用户安排的实现执行方负责。
- 进度检查方：每小时检查公共总表及当前阶段账本，对照其中登记的提交与测试证据。仅维护本检查记录、报告新增完成/缺失/冲突/阻塞，不修改实现，不代跑验收、不合并、不打Tag、不启动或占用服务。
- 不按编辑工具定义角色；任何接手者沿用同一文档链。当前用户指定实现与验收由 Cursor 继续，当前会话仅负责定期检查。
- 遵守占用：不读写锁定路径、未提交文件或未登记工作树；不扫其他执行方目录。需要进一步核实的代码由实现方在公共账本提供已提交证据后，检查方读取该提交内容。
- 不重复创建实现任务、不向外部人员发消息；问题写回公共记录。未经新安排不自行接管实现。

## 检查记录格式

时间 / 读取的账本版本 / 新完成及提交 / 验收层次（Mock、真接口、真库）/ 剩余TODO / 阻塞或需要产品决定。

每次仅追加实质变化；无变化时不制造新完成数，按用户每小时汇报要求简述无新增证据。文档更新遵循提交推送规则；未推送不称备案。
