## 结论先行

**¥198/月不是“多几个主题、多放一点照片”的价格带。** 在成熟产品中，它通常对应三种明确可感知的价值：

1. **重资产容量**：用户把大量、不可替代的数据托付给平台；
2. **高频生产力**：用户每周都用，且功能直接节省时间或创造结果；
3. **多人协作与控制权**：家庭或团队共同使用，带来权限、恢复、管理等复杂能力。

Echo 若维持 ¥198/月（**二档**），应定位为：一个家庭/亲友共同维护的私密数字记忆库，而不是“一个人的高级宠物主页”。若首发尚不能交付家庭协作、原件归档、智能整理与长期恢复，不能把二档先摆成主销档。

## 可借鉴的能力，不照搬表面功能

| 市场证明的付费逻辑 | Echo 的产品化翻译 | 用户听得懂的包装 |
|---|---|---|
| 容量 + 可靠保存 | 原图/原声/长视频归档；多端备份校验；可下载档案包 | **把零散照片、语音和故事，一起好好收住。** |
| 历史版本 + 恢复 | 回忆集版本、误删恢复期、成员误操作回退 | **一次误删，也不会把共同记得的东西弄丢。** |
| 细粒度权限 | 管理者/共写者/投稿者/访客角色；单条可见范围；链接时效/撤回/水印 | **谁能看、谁能补充、谁只能安静地看，都由你决定。** |
| 成果生产工具 | 从素材自动生成可编辑时间线、阶段回顾、纪念影集/网页；不是虚构宠物人格 | **不是又一个相册，是一份能回看的陪伴档案。** |

| 多人协作 | 家庭空间；邀请、审批、署名、分支稿、共同时间线 | **一段陪伴，不必只由一个人独自保存。** |

## 二档（¥198/月）：最低可成立权益包

这是一档**家庭单位**订阅（建议含 4–6 位成员），不是按单用户卖。下列权益需要作为一个整体出现，才足以接近 ¥198/月的认知锚点：

1. **家庭记忆库**：不限回忆集/宠物位；成员可分别投稿，管理员审核发布；每条记录保留署名与编辑历史。
2. **高保真归档**：家庭共享的大容量原图、原声、长视频空间；上传状态、备份状态和容量使用可见；全量档案包可导出。
3. **守护与恢复**：90–180 天误删恢复、历史版本回退、异常登录提醒、成员/链接权限回收、账号继承/指定守护人机制。
4. **“把素材变成回望”**：自动按时间、地点、人物、宠物整理；支持自然语言检索；生成可编辑的周年回望、共同时间线、家庭纪念页。AI 只处理用户授权素材，生成结果标明来源、可逐条修改。
5. **受控的共同纪念**：管理员、共写者、投稿者、仅查看四角色；单条内容独立设为私密/受邀/链接/共鸣厅；外部链接可设置有效期、密码和随时撤回。
6. **跨代传承入口**：指定 1–2 位守护人；本人长期不活跃时按预设流程通知守护人，**绝不自动公开**，只提供授权接管或完整导出。

### 不应放进二档的权益

- 共鸣厅推荐加权、更多“记得”、更亮的暖光、评论置顶；
- 虚构宠物/故人的发言、用“它仍在等你”刺激续费；
- 把基础隐私、删除、撤回、基础导出锁进会员；
- 人工整理、实体册、线下服务（这些会拉长履约链条，也偏离纯数字订阅）。

## 给产品的关键验收问题

在购买页前，用户必须能看到一个自己的结果预览，并能回答：

1. 我的哪些原件会被怎样保存，出了问题能恢复多久？
2. 家人进来后，谁能看、写、删、邀请别人？
3. 我今天付费后，三个月后会新增什么可回看的东西？
4. 若我取消订阅，哪些内容仍可见、可下载，哪些只是停止新增服务？

四项任一答不清，¥198/月就不该开售。
