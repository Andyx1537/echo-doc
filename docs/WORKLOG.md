- 《人工智能拟人化互动服务管理暂行办法》（🔴 **2026-07-15 已施行**）**第 22 条第 1 项**：**「上线拟人化互动服务的」即触发**安全评估并向**省级网信部门**报告。
- 🔴 **它不看用户规模** —— 与「具有舆论属性或社会动员能力」那类以影响力为门槛的规定不同，**这一条以「上线」这个动作本身为触发条件**。⚠️ **「等做大了再合规」在这一条下不成立。**

**🔴 对外承诺须与协议同源（`COPY-GUIDE §2.8`）**

- **任何对外承诺，必须能在用户协议 / 隐私政策里找到同一句话。协议里没有的，文案里不许出现。**
- 依据《民法典》第 498 条末句「**格式条款和非格式条款不一致的，应当采用非格式条款**」：用户协议是格式条款，🔴 **而客服的个别承诺、活动页的具体文案很可能被认定为非格式条款**。
- 🔴 **由此得出一条反直觉的结论**：**一句写在活动页上的话，效力可能高于我们精心起草的用户协议。** 客服随口给出的承诺，也可能盖过协议里那条免责。
- ⚠️ 🔴 **不要读成「文案要写得保守」** —— 它说的是**一致性**不是保守性：协议里承诺了的**尽管大方地说**；协议里没有的，**说得再小心也是新增了一项义务**。

**「永久保存」与「不因长期未登录删除」的口径已合并**

- 两句话并排读会互相削弱，现合并为唯一对外口径：**「我们不会因为你很久没来就删掉它。」**
- 🔴 **不用「永久」二字**，⚠️ **同样不用「永远保存」「终身保存」「一辈子都在」** —— **换个词不换意思等于没改**。判据不是有没有出现「永久」这个字，是**这句话承诺了一个我们无法保证的期限没有**。
- ✅ **可以大方说的是「不因长期未登录而删除」** —— 🔴 **它约束的是我们不做某个动作，而不是保证某个期限**，是一句可履约的承诺。

**召回通道**

- 旧内容退出召回池但不退出索引;分类与相似度召回同样按时间取舍,旧不如新,不承担旧内容兜底职责。产品含义见产品侧。
- 新增 **`SURGE` 热点召回**:已流掉的内容热度突增可拉回,有效期 1 天。触发 `surge ≥ 5` 且 `surge ≥ 3 × base`(地板保护小内容、倍数约束大内容,反马太);五道防刷,含「触发窗口内互动账号与作者存在关注关系占比 >50% 则作废」;终身 2 次 + 冷却 30 天;走独立通道不做权重回升,不占保底位。与 `REVIVE` 的本质区别:**内容自己挣回来的,不是平台按「没人看它」发配额。**
- **15% 冷启动保底位保留**,比例不变,构成由「2 新 + 1 复活」改为 3 位全给新内容。保底组(新发布)必须**全库直查**,否则实际生效比例会缩到 5%。
- 关注通道 `SUB` → `FOL` 及 slug 改名,随产品侧术语定案执行。

**技术选型与实现**

- 向量存储:**先 pgvector + HNSW**,Redis 作为可执行预案待触发。理由是授权状态已在 Postgres,Redis 需另做同步、存在不合规窗口。
- 曝光计数:实时缓存 + 异步定期落库。
- 分享预览图(og:image)需把 AI 标识**叠进图里**——角标是客户端渲染的,分享到站外只有静态图,这是合规缺口。标识规则本身见产品侧。

**测试数据标记**

- 测试数据双正交标记:账号 `isSeed`、内容 `originType='seed_ops'`;总闸 `VITE_SHOW_TEST_DATA=0` 可一次性摘除。**不往 `accountType` 里加值**——它回答「谁在说话」,测试标记回答「数据真不真」,混列会改变后端所有 `accountType='user'` 过滤条件的含义。

**实质问题与处置**

1. 🔴 **`t_memory_card.originType` 字段根本不存在**,字段表与 `schema.sql` 均无——意味着官方号隔离规则此前**全部落不了地**。已补,并登记为北极星统计开启的前置闸门 `G-1`(口径见市场侧)。
2. `SPEC:815`「7 天或 200 次先到为准」与 `SPEC:817`「至少 700 次曝光机会」在供给不足时不可能同时成立,会把**我们自己的供给不足记成内容的失败**。改权重制后该矛盾自动消失。
3. `ResonanceService.queryResonance` 每次调用都写 `t_resonance_record`,而该表无消费方。P0 删除。
4. 引擎缓存缺陷:`CachedPgRepository` 的 `SimpleCache` 忽略 `maxElements`,存在无界增长与 OOM 风险。P0 **不单独修**,只删写副作用 + 加缓存用量观测埋点。
5. `TC-RANK-49` 过标准为「仍能拿到复活保底位」,`REVIVE` 删除后必然失败,判据改为「仍可被搜索与作者主页访问,且够格时可经 `SURGE` 回来」。

### 市场侧

#### 重点完成

- 后台指标:`SPEC-admin-console.md` 北极星口径定稿、官方号运营指标落位(§2.6b)。
- **站外分享的 AI 标识合规缺口已定位并写进规格**(`SPEC-trust-and-compliance §CM-G0S S-11`),结论为**阻塞上线**(与分享功能同批 P0)。唯一降级路径是关闭含 AI 成分内容的站外分享,但 `aiGenerated` 覆盖唤醒视频、回声、AI 封面等 MVP 主力内容形态,该降级近似等于关掉分享,**仅作应急阀门、不作排期退路**。

#### 定论

**北极星口径**

- 北极星 = **被接住的发布率**(废除「捕获率」一词)。`R1–R5` 计入,`R6`(关注题材)/ `R7`(关注 ta)不计入;**过审时刻起算**;兜底回应不计入。
- 官方号内容**整条不进分母**,不是只从分子剔除。采用正向白名单 `originType='user'`。只剔分子会把官方号的卡算成「发了没被接住」,反而压低北极星。字段落地与前置闸门 `G-1` 见技术侧。

**指标分层**

- 订阅与北极星脱钩,单独成一类互动并有独立指标组(净新增 / 曝光转化 / 30 日留存 / 取关率),仅平台观测,不衍生 C 端榜单。
- 官方号两项运营指标归**健康度层 §2.6b**,不进用户活跃层——避免运营加班表现为用户变活跃。
