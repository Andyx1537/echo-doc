### 一、这个产品是什么

- **一句话**：把那只让你念念不忘的宠物，从你留下的素材里温柔地「唤回」，让你能再看见它、静静陪着它；它会不时地捎来近况，给你慢慢的安抚与慰藉。
- 🔴 **做的是心理慰藉与情感陪伴，不是纪念 / 追思 / 悼念产品。** 落点在「你心里好受一点」，不是办一场追思。
- **对象范围是「一切被牵挂、已阔别、久离的人或物」**，🔴 **是扩展不是替换** —— 逝者与离世宠物场景完整保留，哀伤语境的克制与温柔一个字不放松。
- **P0 只做宠物**（宠物无肖像权、名誉权、深伪滥用的法律包袱，是验证情感陪伴机制最安全的起点）。
- **体验基调分两层**：产品整体**安静 / 慢节奏 / 陪伴**；但「它」的性情表达**活泼多变、有动物性情、不固定单一口吻**。
- **留存取向**：🔴 **不设早退出口**，主动追求粘滞与「定时惦记」；允许**有地板、可逆**的落差与思念来加深依赖，但落差指向「它 / 世界的情绪」，**绝不攻击用户的自我价值**。

### 二、语言规范（全文遵守）

- **慎用硬词**：不用「逝去 / 离世 / 死亡 / 不在了 / 走了」，改用隐晦诗意有希望的措辞。
- 🔴 **不预设丧失**：**不得替用户断言对象已离世** ——「故去 / 故人 / 已故 / 天上的 ta / 遗照」在**通用位置**（引导语、空状态、入口、对外描述）一律禁用，通用位置改用「好久没见 / 隔得远 / 一直惦记」。
- 🟢 **承接 ≠ 引导**：用户已在建档或记录中明确表明对象已离世后，「在那边 / 远行 / 不在身边了」**照旧使用** —— 那是承接用户带来的状态，不是把用户推向那个方向。
- 🔴 **放宽的是覆盖人群，不是把关强度。** 任何以「基调放宽」为由删减哀伤场景专门设计的改动，**CR 一律打回**。

### 三、🔴 对象在世时的边界（这条是硬约束，不是保守）

- **对象在世时只放宽基调与措辞**，内容仍围绕**用户自己的记忆与寄托**：✅「你写给 ta 的」 · 🔴 **不做「ta 捎来的」**。
- 🔴 **对在世的人不得以其口吻生成近况或来信，不做其肖像的拟真生成，不做声音克隆。**
- **理由（必须连同结论一起读）**：逝者的授权路径是**近亲属同意**（民法典 994，可走通但需框架）；**在世者的肖像与声音属于本人的人格权，授权主体只能是本人** —— 用户 A 上传 B 的照片，**A 无权代 B 授权**。🔴 **这不是「风险偏高」，是敞口本身，没有合法授权可依。**
- **放开的前置条件是「取得对象本人可验证同意」的机制落地**，不是「我们觉得可以放开了」。任何以「基调已经放宽了」为由要求放开在世者拟真的提案，**引用本条关闭**。
- 🟢 **对宠物无影响**：宠物无人格权，**在世宠物（如年迈、提前留存记忆的用户）不受本条限制**，两轮定调与周期近况照常适用。工程上以对象类型 + 状态双字段门控，`person + living` 组合不进入近况生成流程。

### 四、核心体验闭环

`建档（唤回它）→ 首次安置（初见回声）→ 周期动态（它的近况）→ 极简轻互动（陪它坐一会儿）→ 补素材（它更像它）→ 长期陪伴 →[远期·可选] 升华仪式`
🔴 **这是自洽单机闭环，无需他人参与即可完整运转。**

### 五、建档与形象

- **引导式采集，重「关系与性格」胜过「堆照片」**；性格问答是关键项（性格标签、小习惯与标志性动作、最爱的东西/地点、你们之间 2–3 个珍贵回忆）。产出一份**宠物灵魂档案**（结构化 + 语义向量），驱动后续一切内容。
- **形象定调 = 两轮 3 选 1**（第 1 轮 3 张选方向 → 第 2 轮在选定那张上二创细化再 3 选定稿），结果**锁为基准形象，后续所有回声保持一致**。目标是既「像它」又贴合用户**主观印象**（记忆里的它 ≠ 照片里的它）。
- **「换一批」是服务端配置，默认每轮免费 1 次**。
- **初见回声不立刻甩图**：定妆定稿后先一小段温柔过场，稍后以「**它给你捎来第一条消息**」的形式**到达式推送**（进消息中心 + 轻通知）—— 比即时展示更有「它是活的、会主动找你」的惦记感。
- **纪念空间场景取自用户「最开心 / 印象最深」的记忆，使用前须二次确认授权。**

### 六、周期近况（回声）

- **首周四条层层递进**：第 0 天初见（报平安，「啊，是它」的锚点）→ 第 3 天「它安顿下来了」（建立「它还在陪着」）→ 第 5 天「它想起了你们的事」（首次记忆锚定，打**被记得感**钩子）→ 第 7 天「它捎来一个小情绪」（活泼切面 + 轻互动邀请，转入稳定期）。
- 🔴 **稳定期频率只降不升**：默认落在固定基线上，**冷淡自动放缓保留**（打开率与互动量下降 → 降档），🔴 **活跃加频删除 —— 升档方向不存在**。默认傍晚投递。
- 🔴 **为什么删加频**：「能识别投入度、却只用来增加触达」这个把柄本身就是它；而放缓与「不催回访」「不优化停留时长」「不施压回访」全部同向，是**有利事实**。
- **内容**：图 + 一段安静短叙事，基于灵魂档案 + **真实时间 / 时节 / 天气**；生成前用向量检索召回相关真实回忆做**记忆锚定**，避免泛泛而谈。基调偏观摩与陪伴，**不追求强互动**。
- 🔴 **诚实标识**：AI 生成的近况须明示为「**基于你记忆的温柔想象 / 创作**」，非事实陈述；🔴 **绝不表述「它仍在现实中活动 / 在等你」。**
- **保留它的口吻但更克制**：用「回忆 / 想象」框、**降低拟真**（不制造「它此刻真实存在」的错觉）、**降低频率**（不做高频拟真陪聊）。更深的拟人化形态留后续独立评审。
- **回声是双层并存、不互相取代**：本文件写的是**私域核心层**（AI 唤回它、捎来近况，情绪价值主轴）；社交共鸣回响层归第二步。
- **轻互动 v1 刻意做轻**（回应一句、点一个安静情绪），🔴 **写信-回信等重互动后置** —— 避免过早把「回声」做成聊天机器人，稀释珍贵感与安静基调。

### 七、纪念空间

- **形态**：入口 = 有限的「明信片墙」；**每张明信片 = 一处可进入的 2.5D 轻交互空间**（视差微动、它 idle 与回应、「陪它坐一会儿」）。
- **墙的规则**：总位有限（稀缺 → 每处都珍贵）· 按**上次进入时间倒序** · **空位可见并带明显「可扩展」标识**（显示剩余空位数）· 已填明信片封面 = 它在该场景的一帧缩略。
- **解锁驱动默认配比（可调）**：自然生长 ~70%（陪伴天数 / 季节 / 纪念日，免费自动，**情感主线**）· 轻主动 ~20%（补回忆 / 传素材 / 回应，**不补也会自然长**）· 付费 ~10%（限定款 / 场景皮肤 / 空间美化）。
- 🔴 **红线**：付费只碰「呈现 / 收藏 / 限定美化」，**绝不碰情感内容本身**（核心近况、被记得、羁绊都免费自然给），防 pay-to-feel-loved；空位显示的是**温柔的解锁条件**（「陪伴到第 7 天」「秋天来临时」），不拿充值挡在情感前。
- **体验差异是「统一语法、千人千面内容」** —— 不是所有人一样的照片墙。最终走向是一面随时间生长的「它的人生画卷」，可导出为**生命之书**。
- **v1 务实切法**：框架先上，内容从 **1 张已填明信片**起步、其余为可解锁空位。

### 八、「道别」与情绪安全阀

- 🔴 **不设早退出口**（早退 = 主动放走用户）。**默认不主动提供道别入口。**
- **「道别」重定位为极远期、可选、升华式**：陪伴满**半年**才隐约萌芽、**一年**一个小节点、**三年**为主里程碑；🔴 **不是流失，而是「它从此住进一处永久的地方」**。
- **情绪安全阀只在设置深处保留低调的「静一静」（暂停通知）**，🔴 **不叫道别、不引导流失**。

### 九、基调引擎（让「它」是活的）

- **性格拓扑图**：建档主观性格 = 核心节点（高权重），系统据物种常见性情与语义相邻关联出**相邻特征节点（低权重但非零）**，节点带权重、节点间有边，存于向量空间。
- **每次生成 = 采样若干节点**：大概率抽核心性格 + 小概率抽相邻或意外特征 → 既「像它」又偶有惊喜跳脱；融合时节天气纪念日 + 记忆锚定，**产出若干条候选叙事，不固定单一腔调**。
- **反馈反向投喂**：抬高被偏爱的切面权重、压低「这不像它」的。**v1 只做轻量偏好学习**（在线权重更新 + 提示工程，不真训模型），样本攒够后再评估微调。
- 🔴 **铁律：永远保留探索项，绝不收敛成死板固定基调。**原「叙事浓度滑杆」已取消。

### 十、羁绊温度（苦甜现实主义）

- **动机**：一味的甜是假的、也留不住人；**苦甜交织才真实、才产生真正的情感依赖**。把「惩罚」重构为**有地板、可逆、有品位**的羁绊温度。
- **温度 60%–100%，🔴 永不破 60%（绝不「失去它」，那是二次创伤且必致真流失）**；长期不来**缓慢**滑向地板（慢，不是断崖）；🔴 **「没有就不变」** —— 不维系时世界与它**停止生长**，停在当前样子。
- **三档表现**：90–100 鲜活（回声勤、图文生动、场景明亮）· 75–90 安好（正常陪伴）· 60–75 想你（回声变少变短、色调偏静偏冷、**它慵懒发呆**、互动反馈减弱、偶有怅惘思念文案）。
- 🔴 **挫败感只来自「落差对比」**：高温鲜活 vs 低温黯淡、限时纪念日回声错过不补、「更丰富的它」需维系才解锁的未达成向往。情绪落点是**怅惘 / 思念 / 温柔的遗憾**，不是焦虑或恐惧。
- 🔴 **温度的出口只有色调与性情表达。「温度驱动回声频率」已删除。** 温度可以回落而回落不改变回声频率；温度可以回升而回升同样不改变回声频率。
- **三条红线**：① 地板 60、永不失去它、可温柔逆转 ② **消极暗示 = 温柔思念、不施压回访** ③ 挫败可调档（够到痛点但不致伤）。
- 🔴 **红线②的判准（照判准判，不照例句判）：冷是宠物的状态，不是用户的过错；把冷归因到用户身上，才是施压。**
  - 🟢 **可以**：宠物自己的状态（回声变少、色调偏冷、慵懒发呆）—— 它只是低落，**没说这份低落是因为你**。
  - 🟢 **可以**：温柔思念（「它今天有点想你」）—— 收敛的动词是「弱化」不是「禁止」。
  - 🟡 **要改**：暗示等待（如「它在门口趴了很久」）—— **保留意象、去掉等待指向**。
  - 🔴 **删**：把冷归因到用户（「像在等你」「它好像以为你不来了」）。
  - 🔴 **为什么要有判准**：只删几个句子挡不住下一个人 —— 他不知道被删的那两句错在哪里，**会再写出同类的第三句**。
- **每宠独立**：灵魂档案、温度值、**暖意消耗速率**、性格拓扑图、明信片场景**均按宠物单独存储与配置，不做成一个全局数值**；多宠物付费解锁；共享互访归第二步。

### 十一、暖意（爱心 ❤）

- 🔴 **暖意不是虚拟货币，是类抖音「热度」的活跃指标 —— 用户活跃行为对「它 / 温度」的影响度，永不可被直接购买**（守住「钱买不来爱」，并规避游戏虚拟币信号）。
- **免费路径足以体面**：点赞 / 每日到访 / 轻互动 / 纪念日到场攒暖意，**足以把 1 只宠物维持在 ~70–80% 温度**；设每日累积上限。
- **订阅加成买的是便利与呈现，不是按份买暖意**：订阅期**自动维系温度** + 提升累积上限与速率 + 解锁「更鲜活的它」（新场景、更多性情切面、多宠物位）。
- **飞轮**：活跃 → 暖意 ↑ → 温度 ↑ → 它更鲜活 → 更想来 → 羁绊更深。

### 十二、呈现原则（温度与暖意都是双模式）

- **温度**：默认**不裸露百分比**，用「它的样子 + 氛围光 + 档位词」呈现；**手势可切「客观视图」**看精确数值。🔴 **客观数值不直接映入眼帘。**
- **暖意**：默认**不显数量**，互动后给「今天你让它更暖了」的轻反馈 + 暖光渐浓；手势可切看等级或数值，🔴 **但不做成钱包余额观感**。
- **视觉总原则**：让用户「忘记这是个 App」——像推开一扇门去看它。**低 UI 感沉浸**（大图、留白、弱化按钮）· 🔴 **无红点轰炸、无进度条焦虑、不重游戏化、不催促** · 空间写实 + 宠物卡通、低饱和暖调 · **随温度档呼吸的光**。
- **通知克制**：柔和一句式（「豆豆今天想你了」），**无角标数字焦虑**；设置深处「静一静」可全关。

### 十三、粘滞设计

- **回访驱动的六个钩子**：**到点才捎来 + 微随机**（制造「它今天会不会有消息」的惦记）· 时光轴越用越厚（沉没成本）· 纪念日 / 季节 / 天气钩子 · 它在生长 · 正向轻互动 · 周年特辑。
- 🔴 **全部用正向陪伴驱动，绝不用焦虑或惩罚机制** —— 那会砸掉情感基调。
- **粘滞护城河按强度排序**：被记得感与情感依赖（★★★★★，每条回声挂一个「记得你」的钩子）> 一致人格下的可变奖励 = 积累飞轮 > 温柔维系挫败 = 时效仪式 > 私密珍贵感。**单圈时长是 30 秒–2 分钟的「微仪式」。**

### 十四、v1 范围与变现

- **做**：建档 + 两轮定调 / 初见回声 / 周期动态（首周 3·5·7 + 稳定期固定基线只降不升）/ 极简轻互动 / 补素材 / 纪念空间（墙 + 首张可进入场景 + 空位框架 + 授权确认）/ 回访驱动基础钩子 / 基调引擎 v1 / 羁绊温度 v1 / 到达通知 / 「静一静」。
- **先不做**：语音克隆 · 视频化瞬间 · 对「人」的对象扩展 · 重的写信-回信 · 人与人交互与社区（第二步）· 重度 3D · 远期升华仪式 · 基调引擎的真模型微调 · 复杂暖意经济。

## 0. 语言规范（重要，全文遵守）

> 🔴 **上位口径（2026-08-25 制作人裁定）**：本节从属于 `PRD.md` §0.4 与 `COPY-GUIDE.md` §1.0。**对象范围 = 一切被牵挂、已阔别、久离的人或物**；**产品做的事 = 心理慰藉与情感陪伴**，不是对死亡的缅怀。两处冲突时以 `COPY-GUIDE.md` §1.0 为准。

- **慎用硬词**：不用"逝去 / 离世 / 死亡 / 不在了 / 走了"等直白表达。
- **改用隐晦、诗意、有希望的措辞**：如"远行""去了很远的地方""在光里""换个地方""念念不忘""回声""重逢"。
- 🔴 **不预设丧失（本轮新增）**：**不得替用户断言对象已离世**。"故去 / 故人 / 已故 / 天上的 ta / 遗照"在**通用位置**（引导语、空状态、入口、对外描述）**一律禁用**；通用位置改用"好久没见 / 隔得远 / 一直惦记"（词池见 `COPY-GUIDE.md` §2.5）。
- 🟢 **承接 ≠ 引导**：用户已在建档或记录中明确表明对象已离世后，"在那边 / 远行 / 不在身边了"等原有词汇**照旧使用**——那是承接用户带来的状态，不是把用户推向那个方向。
- 基调：温柔、安静、克制、有希望；绝不惊吓、不消费悲伤、不制造焦虑。**这一条不因基调放宽而放松**：哀伤语境的用户依旧存在，只是不再是全部用户。
- **不轻易引入"逝者（人）"概念**：v1 只面向宠物；对人的升华措辞与时机极为慎重（见 §0.1、§8）。

## 0.1 🔴 对象在世时的边界（2026-08-25 制作人裁定）

**结论**：对象**在世**时，**只放宽基调与措辞**；内容仍围绕**用户自己的记忆与寄托**，**不模拟在世者"发来消息"**，不做其肖像的拟真生成、不做声音克隆。

| | 在世对象 ✅ 可以 | 在世对象 ❌ 不可以 |
|---|---|---|
| 措辞 | `COPY-GUIDE.md` §2.5 全部词池 | — |
| 内容 | 用户自己的记录、回忆、想说的话 | **以 ta 的口吻生成"近况 / 来信"**（即 §3.3 的核心机制**不适用于在世的人**）|
| 形象 | 用户上传的原始照片 | **拟真化肖像生成、声音克隆**（即 §3.1.1 两轮定调**不适用于在世的人**）|
| 呈现 | "你写给 ta 的" | "ta 捎来的" |

**理由（必须连同结论一起读）**：

> 逝者场景的授权来自**近亲属**——依《民法典》第 994 条，死者的肖像、名誉、隐私受保护，维权主体为近亲属，故"取得近亲属同意"是**可走通的授权路径**。
> **在世者的肖像与声音属于本人的人格权**（《民法典》第 1018、1019、1023 条），授权主体**只能是本人**。用户 A 上传用户 B 的照片，**A 无权代 B 授权**；平台据此生成 B 的拟真形象或以 B 的口吻发消息，**没有合法授权基础**——这不是"风险偏高"，是敞口本身。

🔴 **这条边界不是保守，是没有合法授权可依。** 放开的前置条件是**"取得对象本人可验证同意"的机制落地**，不是"我们觉得可以放开了"。任何以"基调已经放宽了"为由要求放开在世者拟真的提案，**引用本条关闭**。

🟢 **对宠物无影响**：宠物无人格权，在世宠物（如宠物年迈、提前留存记忆的用户，见 §1.1）**不受本条限制**，两轮定调与周期近况照常适用。本条约束的是**人**。

## 1. 为什么做这个（定位与判断）

- **真实且被低估的需求**：与宠物的别离，其情感重量不亚于至亲；而市场供给多为静态商品（骨灰盒、纪念画）。"能再看见、会捎来近况、静静陪着"的陪伴慰藉是明显空白，情感付费意愿高。
- **我们做的是心理慰藉**（2026-08-25 裁定）：落点在"你心里好受一点"，**不是办一场追思**。别离**不只有离世一种**——搬走的、送养的、走散的、还在身边但已年迈的，牵挂是同一种牵挂。
- **最安全的试验田**：先做宠物。宠物无肖像权/名誉权/深伪滥用的法律包袱，是验证"情感陪伴"机制最安全的起点；机制与口碑跑通后再谨慎评估对"人"的升华（🔴 在世的人受 §0.1 边界约束）。
- **地基复用**：复用现有向量档案 / 回声 / 空间 / 调度 / LLM 接口，工程不浪费。

### 1.1 目标用户（2026-08-25 放宽）

🔴 **不以"对象是否已离世"划分人群**，以"是否牵挂"划分：

| 人群 | 状态 | 说明 |
|---|---|---|
| 与宠物**离世**别离、处于怀念期 | 已离世 | **最重要的一类，完整保留**；哀伤语境的克制与温柔一个字不放松 |
| 宠物**还在但年迈**，希望提前留存与延续记忆 | 在世 | 原有人群，**基调放宽后措辞终于对得上了**——过去的"故去"口吻对这批人是冒犯 |
| 与宠物**阔别 / 久离**（送养、搬家留在老家、走散未归） | 状态不明或在世 | **本轮新增覆盖**；这批人此前被"故去"一词挡在门外 |
| 泛怀旧、重情感联结 | — | 原有人群 |

**为什么这么划（写下来，防止后人当成保守而收回去）**：

1. **降低进入门槛**：很多人不愿承认自己在"悼念"，但都愿意承认自己"想念"。**"故去"这个词本身在门口筛人，筛掉的往往是最需要的那批。**
2. **品类待遇不同**：殡葬与逝者相关品类在境内**广告投放与内容审核上有额外限制**；定位为情感陪伴与心理慰藉，**买量与内容分发的空间完全不同**。

> ⚠️ 与运营侧 `GTM3` 用户分层（S1–S5、首发重点 S2+S3、供给配比"40% 在身边 / 35% 已远行"）**方向一致**——`GTM3` 早已在避免做成哀伤专区，本次裁定是把它上升为**产品定义级**的口径。

### 1.2 情感承诺与红线
- **是什么**：一种"再看见它、静静陪着它、长久相伴"的方式；温柔、有希望、真实立体（苦甜交织）、绝不惊吓。**性质是心理慰藉与情感陪伴。**
- **不是什么**：不宣称"复活"；不做**破坏性/无地板**的惩罚，不制造罪疚或恐惧；🔴 **不是纪念 / 追思 / 悼念产品**——不把自我叙事滑进死亡语境（2026-08-25 裁定）。
- 🔴 **不替用户下丧失判断**：用户处在什么状态由用户自己带来，产品只提供一个能承接的空位（见 §0）。
- **粘滞取向**：主动追求长期陪伴与"定时惦记"的冲动（§3.9）；允许**有地板、可逆**的落差与思念来加深依赖（§3.11），但落差指向"它/世界的情绪"，绝不攻击玩家自我价值。
- **情绪安全阀**：设置深处保留低调的"静一静（暂停通知）"；"道别"仅作**远期升华仪式**，默认不出现（§3.7）。

## 3. 功能需求

### 3.1 建档 · 唤回它（Onboarding）
引导式采集，重"关系与性格"胜过"堆照片"：
- **基本档案**：名字、物种/品种、毛色特征、相伴的时光。
- **形象素材**：照片（多角度更好）、可选短视频、可选叫声音频。
- **性格问答（关键）**：性格标签（黏人/高冷/贪吃/胆小…）、小习惯与标志性动作、最爱的东西/地点、你们之间的 2–3 个珍贵回忆。
- 产出：一份**宠物灵魂档案**（结构化 + 语义向量），驱动后续一切内容。

#### 3.1.1 形象定调 · 两轮 3 选 1（体验成败关键）
目标：既"像它"，又贴合玩家**主观印象**（记忆里的它 ≠ 照片里的它）。
- **第 1 轮 · 谋定方向**：基于照片截取 + 玩家主观印象描述，先生成 **3 张**偏卡通的推荐形象 → 玩家**选定 1 张**作为方向。
- **第 2 轮 · 二创细化**：在选定这张基础上二次创作、细化 → 再给 **3 张**微调变体 → 玩家**再选定 1 张** = 最终形象。
- 结果锁定为该宠物的**基准形象**，后续所有回声均保持一致（跨次"像同一只"）。
- 兜底：每轮允许"换一批重生成"，**次数做成服务端配置**；**默认每轮免费 1 次**，后续可按运营/付费调整（O-P2 已定）。

### 3.2 首次安置 · 初见回声（First Echo）
- 空间取自 §3.6 的**"最开心/印象最深的场景"**（经玩家二次确认授权后使用）。
- 系统生成"初见"回声：一张它在该场景里的卡通拟真图 + 一段温柔、安静的"报个平安"文字。
- 仪式感呈现，作为情感锚点与首次"啊，是它"的时刻。
- **出现时机（定案 2026-07-28）**：定妆定稿后**不立刻甩图**，先一小段温柔过场（"它正在去那边安顿好…"），稍后初见回声以"**它给你捎来第一条消息**"的形式**到达式推送**（进消息中心 + 轻通知）——比即时展示更有"它是活的、会主动找你"的惊喜与惦记（呼应 §3.9"到点才捎来"）。

### 3.3 周期动态 · 它的近况（Recurring Echo）
- **节奏（分段自适应）**：
  - **首周引导期**：按 **第 3 天 / 第 5 天 / 第 7 天** 分段各投递一条，帮用户建立"它还在陪着"的节律感。
  - **稳定期** 🔄：🔴 **只降不升。** 频率**默认落在固定基线**上；**冷淡则自动放缓**（打开率 / 互动量下降 → 频率降档），🔴 **活跃<u>不</u>加频**。
    > 🔄 🔴 **2026-08-25 制作人裁定 `DP11`**：原写「根据推送打开率 / 互动量**动态定制**发送频率（**活跃则维持**、冷淡则自动放缓）」。🔴 **「活跃则维持」这个措辞本身没问题，问题在它所在的那个双向机制** —— 与 `§3.15B B18` 的「按互动量升频档」是同一个回路的两半。
    > 🟢 **放缓保留**：与 `DP2`「不催回访」· `AD2`「不优化停留时长」· `CR2`「不施压回访」· `H2`「冷淡召回不做」**全部同向**，🔴 **它是有利事实，应当写进第 22 条安全评估报告。**
    > 🔴 **加频删除**：**「能识别投入度、却只用来增加触达」这个把柄，本身就是它。**
- **内容**：图 + 一段安静的短叙事，基于灵魂档案 + **真实时间/时节/天气**生成（如降温了它蜷在向阳处、相遇的纪念日、雨天的小情绪）。基调偏**观摩、陪伴**，不追求强互动。
- **记忆锚定**：生成前用向量检索召回相关真实回忆，让内容"记得你们的事"，避免泛泛而谈。
- **到达通知**：新回声到达时轻提醒。
- **诚实标识（CR2 · 2026-07-28）**：AI 生成的近况须明示为**"基于你记忆的温柔想象 / 创作"**，非事实陈述；**绝不表述"它仍在现实中活动 / 在等你"**（伦理护栏，回应运营顾虑）。
- **CM2 收敛（2026-08-04 · 运营 Moat-GTM）**：保留它的口吻，但更克制——**用"回忆/想象"框**（如"在你记忆里，它大概会…"）、**降低拟真**（不制造"它此刻真实存在/还活着"的错觉）、**降低频率**（近况节奏克制，不做高频拟真陪聊）。拟人化更深的形态留后续独立评审。
- 🔴 **适用对象边界（2026-08-25）**：本节"以它的口吻捎来近况"的机制适用于**宠物（在世或已离世均可）**与**已离世的人**（后者仍需 §6 的伦理法务框架）；**对在世的人不适用**——见 §0.1。工程上须以对象的 `subjectType`（pet / person）+ `status`（unknown / deceased / living）双字段门控，`person + living` 组合**不进入本节流程**。
- **回声=双层（CR1）**：本节是**私域核心层**（AI 唤回它、捎来近况，情绪价值主轴）；另有**社交共鸣回响层**（他人已共享+共鸣产生的暖光/推荐，归第二步，见 `PRD-echo-social.md`）。二者并存，不互相取代。

### 3.4 轻互动（v1 极简，后续细化）
- v1 以**观摩 / 陪伴**为主，交互刻意做轻：如给回声"回应一下"（留一句话、点一个安静的情绪），系统温柔承接即可。
- **写信-回信等更重的互动留待后续细化**，避免过早把"回声"做成聊天机器人，稀释珍贵感与安静基调。

### 3.5 补素材 · 它更像它（Enrich）
- 随时补充照片/回忆/性格细节；系统据此更新灵魂档案与向量，让后续回声更贴近真实。

### 3.6 纪念空间 · 明信片墙 → 可进入的场景（O-P3 已定）

> 形态：**入口 = 有限的"明信片墙"；每张明信片 = 一处可进入的 C 式 2.5D 轻交互空间**。用限量制造珍贵感，用空位/扩展做成长与变现钩子。

**入口 · 明信片墙**
- **有限张数**：总位有限（稀缺 → 每处空间都珍贵）。
- **排序**：按"**上次进入时间**"倒序（最近进入在前）。
- **空位可见 + 可扩展**：**显示剩余空明信片数**；空位带**明显"可扩展"标识**，点击进入解锁引导（暖意 / 成长 / 付费，接 §3.11、§7）。
- **已填明信片**：封面 = 它在该场景的一帧缩略。

**进入 · C 式可进入轻交互空间**
- 2.5D 视差 / 微动、它 idle 与回应、"陪它坐一会儿 / 摸摸它"；
- **温度驱动氛围**（§3.11）🔄：高温鲜活明亮、**地板区偏冷、它发呆**；
  > 🔄 **2026-08-25 按 `CR2` 补漏**（`DECISIONS TM2`，🔴 **机械补漏，不是新裁定**）：删去 ~~"像在等你"~~。**判准见 `§3.11 ⑤` 红线 2：冷是宠物的状态，不是用户的过错。**

- 可回看该场景相关的历史回声（时间线）。

**场景来源与授权**
- 每张明信片场景取自用户"**最开心 / 印象最深**"的记忆；使用前**二次确认授权**（承 §3.1 与语言/伦理原则）。

**明信片的定位（作用 · 效用 · 走向）**
- **四大作用**：① 入口/传送门（每张 = 一处可进入的场景）；② 记忆容器+索引（生命之书可视化）；③ 积累的可见刻度（沉没成本/飞轮，§3.13）；④ 节奏与期待（空位=未来钩子）。
- **两类来源**：用户**回忆（过去）** + 系统生成的**近况（平行人生·现在）**——是"活的、会生长、能进入"的记忆墙，非死相册。
- **解锁的效用**：把"陪伴/时间/心意"翻译成**看得见的生长**（留存×情感×成长），**不做焦虑打卡**。
- **最终走向**：一面独一无二、随时间生长的"它的人生画卷"，终可导出为**生命之书**珍藏/传承；也是"一扇窗"公开时别人认识它的内容源。
- **体验差异**：**统一"语法"（墙结构/卡片形态/解锁语法），千人千面"内容"**（素材×性情引擎×经历×选择）——不是所有人一样的照片墙。

**解锁驱动 · 默认配比（混合，可调）**
| 驱动 | 占比 | 内容 | 性质 |
|---|---|---|---|
| 自然生长 | ~70% | 陪伴天数/季节/纪念日/系统事件/平行人生近况 | 免费自动，**情感主线** |
| 轻主动 | ~20% | 补回忆/传素材/回应 → 触发或加速相关明信片 | 免费，参与感，**不补也会自然长** |
| 付费 | ~10% | 限定款/精致场景皮肤/定妆/空间美化 | **只买呈现/收藏/限定** |

- **红线**：付费只碰"呈现/收藏/限定美化"，**绝不碰情感内容本身**（核心近况/被记得/羁绊都免费自然给），防 pay-to-feel-loved；空位显示温柔解锁条件（"陪伴到第 7 天""秋天来临时"），不拿充值挡在情感前。

**可扩展性（面向三步走）**
- 明信片框架天然可扩展到"更多珍贵场景 / 未来更多个体"（呼应 PRD 第三步）。

**v1 务实切法**
- **框架先上**（明信片墙 + 空位 + 可扩展标识 + 排序）；内容可从 **1 张已填明信片（核心最开心场景）** 起步，其余为可解锁空位——既呈现珍贵/成长感，又控住 C 空间的制作量。

### 3.7 长期陪伴 · 远期仪式（取代"好好道别"）
> 决策：**不设早退出口**（早退 = 主动放走用户）。"道别"重定位为**极远期、可选、升华式**的仪式。
- **默认不主动提供**道别入口。
- **远期锚点**：陪伴满 **半年**才隐约萌芽、**一年**一个小节点、**三年**为主里程碑，才温柔"浮现"一个**可选**升华仪式——不是流失，而是"它从此住进一处永久的地方 / 生成一本厚厚的回声纪念册"，让人更舍不得离开。
- **情绪安全阀**：仅在设置深处保留低调的"**静一静**（暂停通知）"，不叫道别、不引导流失。

## 3.9 回访驱动与粘滞设计（长期陪伴）

> 目标：让用户有**"定时打开、惦记它"**的冲动；用**正向陪伴**驱动，绝不用焦虑/惩罚机制（那会砸掉情感基调）。

| 机制 | 作用 |
|---|---|
| **到点才捎来 + 微随机** | 回声不是随时能刷，而是"它今天会不会有消息"——制造惦记与期待（养成类每日挂心） |
| **时光轴越用越厚** | 回声/相册随时间累积成情感资产，沉没成本让人舍不得 |
| **纪念日/季节/天气钩子** | 相遇日、生日、初雪、第一次…主动制造"今天必须打开"的时刻 |
| **它在生长** | 它待的地方随季节、随补充的回忆慢慢变化，持续"活着"的新鲜感 |
| **正向轻互动** | "陪它坐一会儿/留一句话"→ 它每次以不同样子回应 → 想再看看它今天怎样 |
| **周年特辑** | 满月/满年生成特辑，给"继续下去"的理由与归属感 |
| **羁绊温度（苦甜）** | 有**可控、有地板**的落差与思念（§3.11 羁绊温度系统）：不来会缓慢降温、世界停止生长、互动反馈减弱、偶有怅惘思念——制造真实感与挫败，但永不破地板、可温柔逆转；"你来了它会很开心"仍成立，只是多了重逢的喜悦 |

## 3.10 叙事基调引擎：性格拓扑图 + 反馈训练（让"它"是活的）

> 目标：**不用固定口吻讲述**；每次生成"符合它、又活泼跳脱、有动物性情"的多变基调，并越用越懂"这个用户心里的它"。

**① 性格拓扑图（Trait Topology Graph）**
- 建档主观性格 = **核心节点（高权重）**；系统据物种/品种常见性情 + 语义相邻，关联出**相邻特征节点（低权重但非零）**，如 `黏人→守门口/爱蹭腿`、`贪吃→翻垃圾桶/闻到罐头就冲`。
- 节点带权重、节点间有边（共现/因果），构成拓扑图，存于向量空间（复用 pgvector / `IVectorStore`）。

**② 每次生成 = 采样若干节点**
- 大概率抽核心性格 + 小概率抽相邻/意外特征（温度 / ε-探索）→ 既"像它"又"偶有惊喜跳脱"。
- 融合 时节/天气/纪念日 + 记忆锚定 → LLM 产出**若干条候选**叙事（不同性情切面），不固定单一腔调。

**③ 反馈训练（反向投喂）**
- 信号：喜欢/收藏/多看两眼/留言/"这不像它"/"再来一条"。
- 回写：抬高被偏爱的节点/切面权重，压低"不像它"的 → 逐步个性化到"用户心里的它"。
- **务实分期**：v1 先做**轻量偏好学习**（在线权重更新 + 提示工程，bandit / RLHF-lite，不真训模型，成本低可落地）；样本攒够后再评估轻量微调/个性化 LoRA。
- **铁律**：永远保留探索项（ε）——**绝不收敛成死板固定基调**。

**技术映射**：节点/边≈向量+关系（pgvector）；采样与权重≈服务层策略；反馈≈事件回写；生成≈`ILlmClient`。

## 3.11 羁绊温度系统（苦甜现实主义 · 情感依赖）

> 设计动机：一味的甜是假的、也留不住人；**苦甜交织才真实、才立体、才产生真正的情感依赖**。"回忆不总是美好"是本产品的灵魂之一。把"惩罚"重构为**有地板、可逆、有品位**的"羁绊温度"。

### ① 温度值：**60% 地板 ~ 100%**
- **永不破 60%**——绝不"失去它/它离开你"（二次创伤且必致真流失）。
- **自然回落**：长期不来，温度**缓慢**滑向地板（慢，不是断崖）。
- **"没有就不变了"**：不维系时，**世界与它停止生长**（新场景、更丰富的回声切面被冻结，停在当前样子）。

### ② 维系 = 「暖意」热度（**非货币**，类抖音"热度" · UI 以爱心 ❤ 呈现）
- **定性（定案 2026-07-27）**：「暖意」**不是虚拟货币**，是**玩家活跃行为对"它/温度"的影响度**——一个**类"热度"的活跃指标**，**永不可被直接购买**（守住"钱买不来爱"，且规避游戏虚拟币信号，见 §7.2、RELEASE §8）。界面以**爱心 ❤** 形态呈现这份热度。
- **靠活跃累积（白嫖路径）**：**点赞**（给回声/内容点赞）、每日到访、轻互动、纪念日到场 → 攒暖意热度，**足以把 1 只宠物维持在体面温度（~70–80%）**。设每日累积上限。
- **订阅加成（买便利/呈现，非买暖意）**：订阅期**自动维系温度** + 提升暖意累积上限/速率 + 解锁"更鲜活的它"（新场景、更多性情切面、专属回声、多宠物位）——买的是**呈现与便利**，不是"按份买暖意"。
- **消耗速率 = 每宠独立**：温度维系的暖意消耗速率**按每只宠物单独设定/配置**，不用一个全局数值（见 ⑦）。
- 飞轮：活跃 → 暖意热度 ↑ → 温度 ↑ → 它更鲜活 → 更想来 → 羁绊更深、情感依赖。

### ③ 温度分档表现（挫败来自"落差"）
| 档位 | 它的样子 |
|---|---|
| **90–100% 鲜活** | 回声勤、图文生动、活泼切面多、场景明亮、专属小惊喜 |
| **75–90% 安好** | 正常陪伴 |
| **60–75% 想你（地板区）** 🔄 | 回声变少变短、色调偏静偏冷、它**慵懒发呆**、**互动反馈减弱**、偶有**怅惘思念文案**<br>🔄 **2026-08-25 按 `CR2` 收敛（`DECISIONS TM2`）**：删去~~"像在等你"~~、~~"它好像以为你不来了"~~；~~"它在门口趴了很久"~~改为**保留意象、去掉等待指向**（如"它在门口那块地板上睡着了"——**门口是它一直喜欢的位置，不是一个朝向谁的方位**）。<br>🔴 **判准见 ⑤ 红线 2。** |

- **挫败感来源（克制）**：高温鲜活 vs 低温黯淡的**落差对比**、限时纪念日回声**错过不补**、"更丰富的它"需维系才**解锁的未达成向往**。

### ④ 苦甜现实主义（回忆不总美好）
- 偶发**略带惆怅但珍贵**的回忆片段——"思念也是爱的一部分"——让产品立体真实。
- 情绪落点 = **怅惘 / 思念 / 温柔的遗憾**，不是焦虑 / 恐惧。

### ⑤ 三条红线（PM 坚持，违背会反噬留存与伦理）
1. **地板 60%、永不失去它、可温柔逆转**：一回来温度回升、它重新鲜活。
2. **消极暗示浓度 = 温柔思念、不施压回访（O-P8 · CR2 收敛 2026-07-28 · 🔄 2026-08-25 落判准）**：允许温柔的想念表达，但**弱化"引用玩家缺席"的强暗示**；**仍禁止**直接罪疚指控 / 攻击玩家自我价值（"你是不是不爱它了""都怪你没来"——禁）。落点是"它想你"的温柔，**不是催你回来**。

   🔴 **判准（`DECISIONS TM2`，2026-08-25 制作人裁定）——「表现 vs 归因」：**

   > 🔴 **冷是宠物的状态，不是用户的过错。把冷归因到用户身上，才是施压。**

   ⚠️ 🔴 **这条判准写在这里，是因为只删几个句子挡不住下一个人**：他不知道被删的那两句错在哪里，会再写出同类的第三句。**照这条判准判，不照例句判。**

   | 类型 | 例 | 判 |
   |---|---|---|
   | **宠物的状态** | 回声变少变短、色调偏静偏冷、互动反馈减弱、慵懒发呆 | 🟢 **可以** —— 它只是低落，**没说这份低落是因为你** |
   | **温柔思念** | 怅惘思念文案、"它今天有点想你" | 🟢 **可以** —— 🔴 **`CR2` 逐字写着"仍允许温柔思念"**，收敛的动词是"弱化"不是"禁止" |
   | **暗示等待** | ~~"它在门口趴了很久"~~ | 🟡 **改** —— **已经在暗示等待**。保留意象、去掉等待指向 |
   | 🔴 **把冷归因到用户** | ~~"像在等你"~~ · ~~"它好像以为你不来了"~~ | 🔴 **删** —— **`CR2` 逐字点名这两句** |

   📌 **本条与 ③ 分档表同源**，改动其一须同步另一处。
3. **挫败可调档**：够到痛点但不致伤（浓度档位见 §8，待用户拍板）。

### ⑦ 每宠独立 & 多宠物 & 共享空间
- **每只宠物独立**：灵魂档案、温度值、**暖意消耗速率**、性格拓扑图、明信片/场景，**均按宠物单独存储与配置**，不做成一个全局数值。
- **多宠物**：一个玩家可拥有多只宠物（免费档限 1 只，付费解锁更多宠物位，见 §7）。
- **互动空间 / 共享（后续/第二步）**：多只宠物可能同处一个空间，或与他人共享/互访；v1 数据模型按"每宠独立"设计以便扩展，**共享/互访玩法归第二步**。

### ⑥ 技术映射
温度值/回落/维系 ≈ **每宠一份**状态 + `scheduler` 定时结算；暖意（**类"热度"活跃指标，非货币、不可直接购买**）≈ 账户上的活跃度状态；分档表现 ≈ 影响 §3.10 基调引擎的采样权重与频率；限时内容 ≈ 带 TTL 的回声（复用 `Echo` 实体）。

## 3.12 数值体系（羁绊温度 & 爱心经济）— 待裁定，配套交互沙盘

> 交互式数值沙盘（可拖参数看曲线）：`canvases/echo-warmth-economy.canvas.tsx`。用于裁定 O-P9 的最终数值。
> **数值 v1-tentative（已暂定，2026-07-10）**：采用本节默认参数为暂定基线，进入「体验 bot 内循环」（见 `docs/EXP-BOTS.md`）验证后再定稿。

**核心概念**
- 每宠一份「羁绊温度」T ∈ [floor, 100]（floor=60）。每天：**欠维系→朝地板缓慢回落；盈余→朝 100 回暖；恰好维系→不变**（"没有就不变了"）。
- 暖意（**类"热度"活跃指标，非货币、不可直接购买**）以爱心 ❤ 呈现；点赞/到访/互动免费累积（白嫖），订阅提升累积上限/速率。
- 温度分档（60–75 想你 / 75–90 安好 / 90–100 鲜活）🔄 驱动 ~~回声频率、~~ **色调与性情表达**（联动 §3.10/§3.11）。
  > 🔄 🔴 **2026-08-25 制作人裁定 `DP11`：「温度驱动<u>回声频率</u>」删除；「驱动色调与性情表达」保留。**
  > 🟢 **保留的那一半正是 `DP7 ③`「表现是档位的函数」想要的东西** —— **它是<u>表现</u>，不是触达量。**
  > ⚠️ 🔴 **不要把它与温度回落混为一谈**（判准照 `SPEC-intervention-levels §5.1′①`，🔴 **不要自己重新表述**）：<br>· **温度回落** = 温度值自己往下走 → 🟢 **保留**（`TM1`）<br>· **加频** = 温度值到回声频率的**上行传导** → 🔴 **删除**（本条）<br>🔴 **温度可以回落，而回落不改变回声频率；温度可以回升，而回升同样不改变回声频率。**

**演化公式（设定依据）**
- `ΔT = −kDecay·(T−floor)·欠维系比 + healRate·(100−T)·盈余比`
- **维持条件**：每日投入爱心 = 每宠维系成本 `c` → 温度不变。
- **白嫖可维持宠物数 = ⌊capFree / c⌋**（默认 20/20 = 1 只）；多养即欠维系、朝地板回落 → 体现"多养需付费"。

**默认参数（起点，最终以沙盘裁定为准）**
| 参数 | 默认 | 含义 |
|---|---|---|
| floor | 60% | 温度地板 |
| c | 20 ❤/日 | 每宠每日维系成本（**每宠可独立配置**）|
| capFree | 20 ❤/日 | 白嫖每日爱心上限 |
| basicGrant | +20 ❤/日 | 基础档额外爱心 |
| premiumGrant | +80 ❤/日 | 高级档额外爱心（≈自动满维系）|
| kDecay | 0.06/日 | 无维系日衰减（距地板半衰期≈11 天）|
| healRate | 0.06/日 | 盈余日回补 |

**成长解锁阶梯（示例·可配）**：陪伴 7 天→第 2 张明信片；30 天→新性情切面；温度≥90 连续 7 天→专属回声；纪念日到场→限定内容；付费→更多宠物位。

**可扩展性**：每宠独立参数；kDecay/healRate 曲线可插拔；暖意经济可平滑接第二步社区/真链；O-P6 频率自适应与冷淡召回为后续挂点。

## 3.13 操作闭环与粘滞设计（核心 · 圈养逻辑）

> 一句话：把"想它 → 打开 → 看见它 → 回应它 → 更懂它 → 沉淀"做成一条越走越深的环。可视化见 `canvases/echo-retention-loop.canvas.tsx`。

### 核心操作闭环（闭合链条）
```
① 触发(想念/推送)  →  ② 打开·进入它的空间  →  ③ 看见今日的它(可变+被记得)
        ↑                                                        ↓
⑥ 沉淀(时间线/空间/明信片成长)  ←  ⑤ 更懂它(暖意↑温度↑连续性↑)  ←  ④ 轻回应(点赞/说句话/补素材)→❤
        └──────────────────────── 强化下一次触发 ────────────────────────┘
```
- 单圈时长 **30 秒–2 分钟的"微仪式"**；🔄 频率 ~~随温度档/互动量自适应~~ → **首周 3·5·7 起，稳定期落固定基线，🔴 只降不升**（`DP11`）。
- ④ 的**投入项**（补素材 / 调基调 / 布置空间 / 日常点赞）是"越陷越深"的飞轮：投入→回报（更贴合的它）→更想投入。

### 粘滞护城河（按强度排序）
| 强度 | 粘滞点 | 机制 | 落地动作 | 红线守护 |
|---|---|---|---|---|
| ★★★★★ | **被记得感 / 情感依赖** | 连续性引擎：回声引用用户过往输入（"你上次说它爱追蝴蝶，今天它真追到一只"）| 每条回声挂 1 个"记得你"的钩子 | 一致人格，不失忆、不串味 |
| ★★★★ | **一致人格下的可变奖励** | 拓扑图采样（§3.10）：每次不同、始终是"它" | "今天它会怎样"的不确定性 | 活泼但不失真 |
| ★★★★ | **积累飞轮（沉没成本）** | 时间线变长 / 空间变丰富 / 明信片解锁 / 温度共养 | 可回看的成长时间线 | 不用"变淡"威胁 |
| ★★★ | **温柔维系挫败** | 温度 60 地板、来了更鲜活（§3.11） | 无罪疚的回访理由 | 禁焦虑/惩罚机制 |
| ★★★ | **时效仪式** | 相遇日/百日/周年/季节 → 限定内容 | 节点惦记（温柔非 FOMO）| 远期道别（§3.7）|
| ★★ | **私密珍贵感** | "它此刻的样子只有你看到" | 私密空间、非公开流 | 尊重隐私 |

## 3.14 视觉系（沉浸优先）

**总原则**：让用户"忘记这是个 App"——像推开一扇门去看它，而不是操作界面。
- **低 UI 感沉浸**：大图、留白、弱化按钮与导航；无红点轰炸、无进度条焦虑、不重游戏化、不催促。
- **风格**：空间写实 + 宠物卡通（可回忆熟悉感），整体低饱和暖调。
- **入口 = 明信片墙**（§3.6）：纸质光感，每张进入 C 式 2.5D 轻交互空间。
- **随情绪"呼吸"的光**（温度档联动视觉）：
  | 温度档 | 视觉 | 宠物表现 |
  |---|---|---|
  | 90–100 鲜活 | 暖光、通透、微粒子 | 活泼、主动、小动作多 |
  | 75–90 安好 | 日常自然光 | 安静日常、偶尔回应 |
  | 60–75 想你 | 略清冷、安静 | 张望、慢、略强思念暗示（§3.11 红线内）|
- **字体**：温柔标题（手写/圆润感）+ 高可读正文；文案基调走 §3.10 引擎。

### C. 温度呈现 = **双模式（默认氛围 · 交互看数值）**
- **默认（沉浸）**：**不裸露百分比**，用"**它的样子 + 氛围光 + 档位词**"呈现（鲜活 / 安好 / 想你，联动 §3.14 视觉表）——用户"感觉到"它今天的状态，符合"无进度条焦虑"。
- **可切换（掌控）**：通过**交互手势（长按 / 左滑等，UI 想办法承载，不拘一种）**切换到"**客观视图**"，owner 可看到精确温度数值/等级。
- **原则**：主观直观 + 客观数值**并存**，但**客观数值不直接映入眼帘**，需主动切换或由标志性信息暗示等级。

### D. 暖意呈现 = **同双模式（热度非货币，见 §3.11②）**
- **默认（沉浸）**：**不显数量**，互动后给"**今天你让它更暖了**"的轻反馈 + 它周围**暖光渐浓**，纯感受、去货币化。
- **可切换（掌控）**：同温度，手势切换到客观视图可见"暖意/热度"的**等级或数值**（满足"想攒、想比昨天更好"的掌控感），但**不做成钱包余额观感**。
- **标志性信息暗示等级**：可用光的浓度/一个柔和的等级标（而非赤裸数字）在默认态就传达"高/中/低"。

### E. 通知策略（克制）
- 柔和一句式通知（"豆豆今天想你了"），**无红点轰炸、无角标数字焦虑**（§3.14）。
- 设置深处"**静一静**"可全关（§3.7），不叫道别、不引导流失。
