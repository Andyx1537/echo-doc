# 03｜Echo 业务与内容安全情况说明（盖章前底稿）

**致：**【受理机关/接入服务商/应用分发平台名称】

我单位【公司全称】拟运营移动互联网应用程序“Echo”（以备案登记名称为准），现就业务内容及信息内容安全管理情况说明如下：

## 一、业务内容与定位

Echo 是回忆记录与共鸣社区。用户可以自主上传、整理、私密保存或公开分享与亲友、宠物、成长经历、旧物、城市等相关的图文回忆；对于故去亲友或宠物的上传和缅怀，是平台提供给用户的一类自主记录与表达场景。

平台不以网络墓园或线上陵园作为产品定位，不提供殡葬、代祭、遗体处置、线下服务撮合，也不以任何方式承诺代表逝者表达意志。平台不从事互联网新闻采编发布、网络直播【如实际关闭】及其他依法需取得专项许可而尚未取得许可的业务。

## 二、发布与可见范围

用户创建回忆内容时可选择“仅自己可见”“凭链接可见”或“进入共鸣厅”。默认仅自己可见；只有用户主动选择公开、并经平台审核通过的内容，才会进入公开瀑布流。公开内容的作者可停止推荐、调整可见范围、关闭互动、删除内容或对用户进行拉黑处理。

平台的互动方式包括记得、献花、同频、安静陪伴和文字回声等。平台首发不开放陌生人私信、群聊、公开视频直播、音频房、人脸/声音复刻【实际开关以 `01` 为准】。

## 三、账号与内容管理

1. 用户浏览可使用基础服务；用户发布公开内容、发表评论/回声等信息发布行为前，应完成手机号码实名核验。
2. 平台建立发布前提示、自动识别、人工审核、举报受理、分级处置、申诉复核和操作留痕机制。
3. 对违法和不良信息、侵害他人肖像/隐私/名誉、网络暴力、诈骗导流、未成年人风险、利用哀伤内容恶意炒作等行为，平台将根据规则采取拒绝发布、限制展示、暂停互动、删除/屏蔽、限制账号、封禁、向主管部门报告等措施。
4. 平台提供内容及账号举报入口，受理侵权、隐私、违法信息及其他用户投诉；对紧急风险内容优先限制传播并进行人工复核。

## 四、组织与应急

我单位已明确内容安全负责人【姓名/职务】、技术安全负责人【姓名/职务】、投诉处理负责人【姓名/职务】及 24 小时应急联系方式【电话】。发生重大网络信息安全事件时，将立即启动预案，采取停止传播、保存日志和证据、风险排查、用户告知及依法报告等措施。

## 五、承诺

我单位承诺遵守互联网信息服务、网络安全、数据安全、个人信息保护及信息内容管理等法律法规和主管部门要求，持续落实实名、内容审核、投诉处置、应急响应等责任；如业务功能发生重大变化，将按规定重新评估并办理相关手续。
