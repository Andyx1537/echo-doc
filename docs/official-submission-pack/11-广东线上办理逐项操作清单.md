# 11｜Echo 广东主体：线上办理逐项操作清单

> 适用前提：Echo 的**运营主体住所地在广东省**。  
> 目标：按“在哪个线上入口办 → 谁操作 → 点哪里/填什么 → 上传什么 → 审核后做什么”推进。  
> 注意：备案、许可、等保互相独立。拿到 App 备案号不等于已经取得 ICP 经营许可证、等保或算法备案。

## 0. 先确定四个负责人和一个事实源

| 角色 | 线上操作权限 | 上线前必须确认 |
|---|---|---|
| 法务/行政 | 主体资料、授权、电子签章、许可证申请 | 公司名称、统一社会信用代码、经营范围、股权、法定代表人 |
| 技术负责人 | 域名、云接入、服务器、包名、安全/等保材料 | 所有域名、IP/地域、云服务商、系统拓扑、SDK |
| 运营负责人 | 服务说明、内容规则、审核与投诉机制、商店资料 | 首发功能开关、社区规则、客服与应急联系人 |
| 安全负责人 | 公安、等保、日志、应急、供应商安全 | 定级、安全方案、漏洞/备份/权限证据 |

所有人只使用 [`01-主体与系统信息采集表`](01-主体与系统信息采集表.md) 的同一套主体、域名、包名和负责人信息。任何一项变更，先更新该表再改各系统。

## 1. 网站 ICP 备案与 App 备案（广东通信管理局链路）

### 1.1 线上入口与帐号

| 项 | 内容 |
|---|---|
| 谁提交 | Echo 先在**中国大陆云/接入服务商**后台创建备案订单；接入商完成真实性核验后，线上递交给广东省通信管理局。App 也可由应用分发平台协助递交。 |
| 广东受理机关 | 广东省通信管理局；但公司不直接去窗口排队。 |
| 结果查询 | [ICP/IP 地址/域名信息备案管理系统](https://beian.miit.gov.cn)。 |
| 账号 | 云/接入商实名账号 + 主体负责人实名核验（具体人脸/短信核验由接入商页面要求）。 |
| 先后顺序 | 先完成主体与网站/域名备案基础信息；再补 App 信息。已有网站备案的主体通常无需重填主体信息。 |

工信部明确：App 主办者填写材料、完成实名核验后，由接入商或分发平台在线提交到**主办者住所所在地**通信管理局；无需到管局窗口排队。广东也执行“先备案后服务”。

### 1.2 在线填写步骤

1. 技术在云服务商备案控制台选择“新增备案/新增服务”，主体类型选企业，主体所在地选择广东。
2. 行政填主体：公司全称、统一社会信用代码、注册地址、法定代表人、主体负责人、服务负责人、手机号/邮箱。必须和营业执照及 `01` 一字不差。
3. 技术逐项添加实际使用的官网、API、H5、分享页域名；填接入商、服务器 IP/地域、服务名称和服务内容。
4. 选择/补充 App 备案信息：中文名称、包名、图标、版本、下载渠道、关联域名、服务内容、负责人；服务描述直接使用 `02` 中的“业务情况说明”。
5. 上传材料，完成接入商要求的负责人核验（通常为身份证件电子件、现场照片/人脸或短信核验）。
6. 接入商退回时，按其意见在控制台修改；接入商审核通过后才会推送广东管局。
7. 管局审核通过后，短信/邮件接收备案结果；在 [备案系统](https://beian.miit.gov.cn) 查询。
8. 客户端在“设置—关于 Echo”或其他显著位置展示 App 备案号；官网页底展示 ICP 备案号及查询链接。应用商店资料同步备案号。

### 1.3 系统中需要填的字段/上传的电子件

| 类别 | 线上字段 | 电子件 |
|---|---|---|
| 主体 | 公司名、信用代码、地址、法人、主体/服务负责人、电话邮箱 | 营业执照彩色扫描件；按页面要求的负责人证件与核验照片 |
| 域名与资源 | 域名、IP、接入商、服务器地域、服务名称 | 域名证书/实名信息、接入证明（按接入商要求） |
| App | App 名称、包名、图标、版本、下载渠道、关联域名、服务内容 | 图标、安装包/下载页/商店页等按接入商要求 |
| 业务 | 服务类型、服务内容、是否涉前置审批 | `02` 业务说明；若勾选新闻、出版、视听等才需相应前置批准文件 |

### 1.4 Echo 填报口径（可复制）

> Echo 为用户提供回忆记录、整理、私密保存、公开分享及轻量互动服务。用户可自主上传文字、图片等素材，建立与亲友、宠物、成长经历、旧物、城市等相关的回忆内容；用户可选择仅自己可见、凭链接可见或经审核后进入公开“共鸣厅”。平台实行发布实名核验、内容审核、举报受理、账号管理和应急响应。开户注册及内容发布不以特定对象或情绪场景为前提，相关回忆内容由用户自主决定是否记录和分享。

### 1.5 线上常见退回点

- 营业执照名、备案主体名、应用商店开发者名、支付签约主体不一致；
- 域名不在该主体名下或未被全部列入；
- App 名称、包名、图标、实际安装包/商店页不一致；
- 服务描述写了“直播、新闻、医疗、殡葬、网络墓园”等实际没有或需要前置核验的内容；
- 负责人电话/邮箱不能接收核验，或现场核验图不符合接入商要求；
- 功能已改（新增 AI、视频、支付域名等）却未申请变更。

### 1.6 结果后的线上维护

- 主体、负责人、域名、App 名称/包名/服务内容变更时，通过原接入商后台提交变更，不要自行等到下次发版。
- 每次 App 发版前，运营核对备案号、名称、主体、隐私政策 URL、功能开关与商店提交信息。

## 2. 经营性 ICP 许可证（收费前的线上专项）

> 条件：如果法务确认 Echo 的自营订阅/付费信息服务需要经营性互联网信息服务许可，广东主体申请省内增值电信业务经营许可证。**先取得专项法律结论；确定要办即提前启动，不能等到付费按钮上线。**

| 项 | 广东线上做法 |
|---|---|
| 官方系统 | [电信业务市场综合管理信息系统](https://dxzhgl.miit.gov.cn) |
| 操作入口 | 登录后选择“电信业务经营许可申请”→ 省内许可证申请 → 按“信息服务业务（仅限互联网信息服务）”等法务确认的业务种类填表 |
| 谁登录 | 法定代表人授权的行政/法务帐号；技术、安全、客服负责人配合填数据 |
| 收费 | 广东通信管理局公开指南显示行政申请本身不收费 |
| 时限 | 材料齐全后，广东公开指南写明：5 日内决定是否受理，60 日内审查作出决定；按退补件次数浮动 |
| 结果 | 可在线下载电子证照；广东允许按需申请纸质证照，电子证照与纸质证照具同等法律效力 |

### 2.1 在线表单逐项准备

| 系统表单/附件 | Echo 填写或上传内容 | 由谁提供 |
|---|---|---|
| 业务发展和实施计划及技术方案 | 用户是谁、怎么用、收费权益、系统架构、运营/客服、持续服务方案；以 `03` 为业务基础 | 运营+技术 |
| 许可证申请表 | 公司基本信息、业务种类、覆盖范围 | 行政/法务 |
| 公司及人员情况表 | 法人、许可负责人、客服负责人、网络安全负责人；最近一个月三名负责人社保证明 | 行政/HR |
| 网络与信息安全保障措施 | 账号实名、审核、隐私、日志、应急、权限、供应商管理；用 `04` 和 `05` 展开 | 安全+技术+运营 |
| 股东追溯材料 | 股东结构、企业信用公示系统完整截图；如涉外资按要求补外资材料/承诺 | 法务/财务 |
| 系统下载的声明/承诺 | 法人签字、公司盖章后彩色扫描上传 | 行政 |
| 互联网信息服务专项附件 | ICP 公共查询截图、接入商后台完整截图、有效网络接入/主机托管协议、App 各核心页截图 | 技术+行政 |

### 2.2 Echo 必须准备的 App 截图清单

1. 注册/手机号核验；
2. 首页“共鸣厅”及主题瀑布；
3. 创建回忆与三档可见范围；
4. 回声/评论的作者控制、举报、拉黑；
5. 内容审核/投诉后台（可提供脱敏截图）；
6. 隐私政策、用户协议、注销、客服入口；
7. 订阅价格、自动续费提示、取消、退款与订单页（如收费）；
8. AI 标识与授权页（如开启 AI）。

### 2.3 审核意见线上闭环

- 每日由行政/法务登陆系统查看“待补正/退回意见”；不得仅靠短信。
- 收到退件后，先在 `01` 确认基础事实，再由对应 Owner 改稿，法务复核后重新上传。
- 许可证取得后，主体、法定代表人、注册资本等发生变化，应按规则在线申请变更；终止服务也需在线申请终止。

## 3. 公安联网备案（网站/域名的线上链路）

| 项 | 广东线上做法 |
|---|---|
| 官方入口 | [全国互联网安全管理服务平台](https://beian.mps.gov.cn)；通过公安部“互联网+政务服务”登录 |
| 办理时点 | 网络正式联通之日起 30 日内办理；以属地公安审核要求为准 |
| 谁操作 | 安全负责人或授权行政；建议使用公司统一留档邮箱/手机号，不用个人私人帐号 |
| 适用对象 | 已上线的官网、H5、分享页等网站业务；App 服务器/业务如何登记，以属地网安指引和接入商实际情况确认 |

### 3.1 线上点击路径

1. 打开 [平台](https://beian.mps.gov.cn)，点击“用户登录”，完成统一身份登录。
2. 第一次使用：新增主体，填企业基本信息与安全负责人。
3. 进入“业务办理”→“网站业务”→“新办网站申请”。
4. 按页面填写网站名称、域名、备案号、服务器/接入信息、负责人、服务类型和安全信息，上传要求的电子材料。
5. 提交后跟踪属地公安审核通知；被退回则在线修改再提交。
6. 审核通过后，在“我的—我的网站—详情”下载备案编号图标和 HTML 代码；将代码放到网站页脚。App 内展示以主管要求/应用商店要求为准，不以网页图标替代 App 备案号。

### 3.2 提交前准备

- [ ] 公安联网备案用的主体与域名与 ICP 备案一致；
- [ ] 已完成网站 ICP 备案并可获取备案号；
- [ ] 安全负责人、联系电话、应急邮箱可长期使用；
- [ ] 官网、分享页、隐私政策页能正常访问；
- [ ] 有基础安全措施证据：HTTPS、后台权限、日志、投诉入口、应急联系人。

## 4. 网络安全等级保护（等保）：广州与广东其他城市要分开办

### 4.1 若运营主体/系统属地在广州

| 项 | 线上做法 |
|---|---|
| 登录前提 | 先注册 [广东省统一身份认证平台](https://tyrz.gd.gov.cn) 帐号 |
| 办理入口 | [广州市公安局](https://gaj.gz.gov.cn/) 首页 → 法人业务 → “网络安全等级保护备案” |
| 电子结果 | 广州公安一体化平台审核通过后可下载、打印电子版《网络安全等级保护备案证明》；公安机关不再发放纸质证明 |
| 咨询 | 广州公开指引的网络备案/定级/测评咨询电话见平台公告；提交前以当期页面为准 |

### 4.2 广州线上流程（不要跳步）

1. 在广东统一身份认证平台注册法人/经办人身份，并完成企业授权。
2. 在广州公安一体化平台新增网络系统，填运营单位、系统名称、业务类型、部署地点、边界、联系人、拟定等级。
3. 提交定级材料，组织专家评审；如有主管/行业监管部门，按要求取得核准；在线申请定级审核，获得《网络安全等级保护定级回执》。
4. 根据定级整改：技术、安全、制度、日志、权限、备份、应急、供应链等；选择合规测评机构完成测评并取得报告。
5. 回到平台在线申请等保备案，审核通过下载《网络安全等级保护备案证明》。
6. 按要求在线提交测评报告，取得提交回执；之后按等级持续整改、复测和变更。

### 4.3 如果系统属地不在广州

- 仍先由安全负责人确定**网络实际部署地、运营主体住所地、属地公安网安受理地**；
- 在当地公安/政务服务门户检索“网络安全等级保护备案”并按当地入口办，不要直接照搬广州平台；
- 可以先电话/线上咨询属地网安，确认系统应按哪个地市提交。材料内容沿用本包 `04`，但上传格式以本地页面为准。

### 4.4 Echo 线上填报的系统边界建议

系统名称建议统一为：`Echo 回忆与共鸣社区互联网信息服务系统`。  
边界包括：移动客户端、Web/分享页、API 网关、账号认证、内容发布/审核、推荐/精选、对象存储、数据库、运营后台、日志与告警；第三方短信、支付、云、审核、AI（如有）在图中标明接口和数据流。  
**等级不是产品自行写死的**：由定级流程、属地公安及测评意见确定；本项目按处理 UGC、账号、图片/人脸等敏感场景，技术上应预留较高等级的安全能力。

## 5. 算法备案 / AI、深度合成（开启时的线上链路）

> Echo 首发若只做运营精选、主题与时间排序，且不对公众开放 AI 生成功能，可暂不走这一条；**一旦上线个性化推荐、公众 AI 图片/文本生成或人像/声音编辑，先由法务确认，再同步启动。**

| 项 | 线上做法 |
|---|---|
| 官方入口 | [互联网信息服务算法备案系统](https://beian.cac.gov.cn) |
| 谁操作 | 法务/AI 负责人注册填报帐号；技术和运营共同提供模型、算法、内容安全材料 |
| 填报维度 | 服务主体、服务形式、应用领域、算法类型、算法自评估报告、拟公示内容；深度合成/生成式 AI 另按系统及适用规则填报 |
| 时限 | 对具有舆论属性或社会动员能力的算法推荐服务，规定要求自提供服务之日起 10 个工作日内备案；变更 10 个工作日内办变更、终止 20 个工作日内注销 |
| 通过后 | 在 App/网站显著位置展示备案编号和公示信息链接；持续维护变更与年度/专项核验要求 |

### 5.1 上线前必须备齐的线上附件

- 算法/AI 服务功能说明、用户流程、功能截图和版本号；
- 推荐机制或模型的基本原理、用途、输入数据、输出、人工干预、关闭入口；
- 算法自评估报告和安全评估材料；
- 内容审核、投诉举报、应急处置、用户标签与个人信息保护说明；
- AI 标识（显式/隐式）、用户声明、生成溯源、训练授权、肖像/声音单独同意的证据；
- 模型/云/审核供应商、部署地域、数据出境判断和责任分工；
- App 内拟展示的备案号位置截图。

本包的 [`07-算法与AI服务评估预审表`](07-算法与AI服务评估预审表.md) 是上述材料的填报索引。

## 7. 广东主体的实际排期（线上可并行）

| 第几天 | 在线动作 | 前置依赖 | Owner |
|---:|---|---|---|
| 1–3 | 填 `01`，开云/接入商备案帐号，盘点域名、包名、服务器、SDK | 公司主体已设立 | 技术+行政 |
