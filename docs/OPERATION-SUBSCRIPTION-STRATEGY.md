# 回声·往宠 — 免费与订阅并行的运营策略

| 项 | 内容 |
|---|---|
| 定位 | 订阅不是“晚点再做的变现”，而是 P0 起就要验证的长期服务承诺 |
| 核心判断 | **免费保证用户能完整地留下与共鸣；订阅提供更强的保存、呈现、协作和持续服务。** |
| 目标 | 让免费与付费形成清晰、可信、非羞辱式的差异，而不是把爱和被记得锁进付费墙 |

---

## 1. 策略纠偏：订阅应从第一版并行，而不是等免费用户做大

若 Echo 只提供免费情怀内容，会重演大多数怀旧/内容社区的问题：用户可以看、可以感动，却没有足够理由长期付费，平台也没有资源承担内容审核、存储、客服和长期保存承诺。

因此 P0 的正确策略是：

```text
完整免费纪念与共鸣体验
        +
从首发同步提供的订阅服务
        +
用“长期保存与更好呈现”的持续价值建立信任和续费
```

这不是“先免费后收费”，而是两个清楚的产品承诺同时存在：

- **免费承诺**：你可以留下它、发布它、被共鸣、带走基本纪念；不会因为不续费而失去它。
- **订阅承诺**：如果你希望把这段陪伴保存得更完整、呈现得更丰富、与更多亲友共同维护，Echo 会持续投入服务能力。

---

## 2. 订阅边界：哪些必须免费，哪些可以成为服务价值

### 2.1 绝对不付费化的“情感公地”

以下能力必须免费且不因订阅到期被收回：

| 免费权利 | 原因 |
|---|---|
| 创建一份基础回忆集 / 一张基础纪念页 | 这是产品的根，不应变成“付不起就不能留下” |
| 浏览共鸣厅、发布基础回忆卡 | 发布是生态供给，不应成为付费创作者门槛 |
| 记得、基础回声、被记得 | 共鸣是社区语言，不能成为会员特权 |
| 基础隐私、撤回、删除、举报、内容控制 | 安全与尊严不应收费 |
| 基础导出与到期后的只读访问 | 不能把用户回忆当作续费人质 |

### 2.2 订阅购买的是“纪念服务增强”

| 价值维度 | 免费档 | 订阅档 | 用户愿意为之付费的真实理由 |
|---|---|---|---|
| **保存深度** | 1 个基础回忆集、有限精选媒体、基础导出 | 多回忆集/多宠物、更大高清图/音视频容量、完整原件归档、批量导出 | “我不只想留一页，我想把它完整留下” |
| **呈现品质** | 基础纪念页与主题 | 纪念页主题、场景、时间线、周年特辑、高清纪念册 | “我想把它做成真正属于我们的作品” |
| **整理能力** | 基础时间线、手动记录 | 智能整理、主题自动归类、回忆检索、月度/年度回顾 | “照片太多，我想重新找到它们” |
| **共同传承** | 个人使用 | 亲友共同编辑、家庭可见页、授权协作者、共同纪念册 | “不只是我一个人记得它” |
| **持续服务** | 基础通知与账户 | 长期托管承诺、纪念日归档、优先客服、迁移/恢复协助 | “我希望多年后还能稳稳找到它” |

### 2.3 明确不卖什么

- 不卖“被记得”次数、暖光、评论优先级、共鸣厅曝光；
- 不卖“它是否还在 / 是否更爱你 / 是否不离开”的情感承诺；
- 不把用户的基础发布、撤回、删除、导出、隐私保护设为会员权益；
- 不因取消订阅删除回忆、降为不可读取或用高频催费打扰。

## 4. 免费与订阅如何形成“能感知、但不伤害”的差异

### 4.1 不是砍免费功能，而是让免费先感到价值

免费用户必须先完成：看见一段共鸣 → 留下一张自己的回忆 → 收到一次恰当回声 → 回看自己的空间。

此后，订阅在三个“自然想要更多”的时刻出现：

| 用户时刻 | 可出现的订阅价值 | 不应出现的说法 |
|---|---|---|
| 想再放入照片/声音 | “把这一段也一起好好归档” | “空间不够，快付费不然丢失” |
| 想把回忆做成作品 | “把这些片段整理成一册可保存的纪念” | “付费才能解锁完整情感内容” |
| 想和亲友一起维护 | “邀请也记得它的人，一起补完这一页” | “不付费就不能让家人看见” |
| 临近周年/季节回顾 | “这一年留下的片段，想不想整理成一份回望？” | “今天不买，它会难过” |

### 4.2 转化不是硬拦截，而是服务试用

建议 P0 做三种低压力验证：

1. **首次完成回忆集后**：给 7 天会员体验，展示整理、主题、归档，不自动续费、不要求先绑支付；
2. **形成第二段有价值素材时**：展示“完整归档/年度册”的成果预览，允许先看成品再订阅；
3. **有亲友共鸣或邀请需求时**：展示共同纪念页的样例和权益，不把基础分享锁死。

运营要测试“用户愿不愿意为保存/呈现买单”，而非测试“用户是否会在脆弱时被支付页推动”。

## 5. 订阅是信任服务：取消与到期规则

订阅品类的护城河来自长期信任，取消体验比付款页更能说明品牌。

| 场景 | 必须做到 | 禁止 |
|---|---|---|
| 用户取消 | 一步可取消、明示服务到期日 | 隐藏入口、情绪施压、复杂挽留 |
| 订阅到期 | 内容永久保留；超出容量的内容只读/可下载，给合理宽限 | 删除照片、封锁纪念页、马上限制访问 |
| 用户回归 | 记忆完整恢复；解释可恢复的服务 | 用“它一直在等你”召回 |
| 数据迁移 | 可下载基础资料；高阶导出按服务约定提供 | 将数据锁在平台内 |

运营口径：**“你订阅的是我们的长期服务，不是对回忆的使用权。”**

## 6. P0 就应验证的订阅指标

| 指标 | 说明 | 运营决策用途 |
|---|---|---|
| 价值触达率 | 完成一次核心体验后，看到与自己行为相关的订阅价值页的比例 | 判断触发时机是否自然 |
| 试用启用率 | 用户主动领取会员体验的比例 | 判断价值表达是否有吸引力 |
| 试用功能使用率 | 使用归档/主题/年度回顾/共同编辑等服务的比例 | 判断卖点是否真实被需要 |
| 试用转订阅率 | 到期前主动订阅的比例 | 验证价格与价值匹配 |
| D30 订阅留存 / 取消原因 | 用户是否持续感到服务价值 | 指导权益与价格调整 |
| 免费用户健康度 | 免费发布、共鸣、续发是否受付费页伤害 | 防止“付费化”损伤生态供给 |
| 订阅用户内容安全/投诉率 | 付费是否让用户产生被消费感 | 品牌红线监控 |

### P0 假设门槛（供内部试验，不对外承诺）

- 有核心体验的用户中，≥20% 主动进入订阅价值页；
- 领取体验者中，≥35% 使用至少一项订阅服务；
- 付费判断不只看转化，必须同时满足免费用户发布/共鸣健康度不下降、投诉/撤回不升高；
- 若用户普遍只为“多存照片”付费，优先加强归档；若为“做成册/共同写”付费，优先发展服务与协作。

## 7. 运营与产品对接事项

| 运营要验证的命题 | 产品需提供的能力 | P0 交付物 |
|---|---|---|
| 用户愿为长期保存付费 | 订阅状态、容量/归档权益、取消后只读策略 | 会员服务中心 + 容量/归档能力 |
| 用户愿为呈现付费 | 主题页、纪念册预览、年度整理 | 成果预览页 + 一种可购买服务 |
| 用户愿为共同传承付费 | 邀请协作/家庭页的受控试点 | 邀请等待名单或小范围 beta |
| 免费与付费能共存 | 同一社区内不同权益的清晰边界 | 权益矩阵 + 不破坏共鸣的文案 |
| 付费不伤害信任 | 取消、到期、导出、恢复 | 订阅生命周期与客服 SOP |

### 需要确认的运营决策

1. 以一档（¥39/月）作为主力订阅的第一测试点，是否确认？
2. 二档（¥198/月）是否以纯数字月订阅形态，在 P1 以限量 Beta 方式验证？（⚠️ 原问句里的档名「家庭守护」已按 `NM1` 撤下）
3. P0 是否开放 7 天、无自动续费的会员体验？
4. 首批付费服务优先选“完整归档”还是“纪念册/年度回顾”？运营建议两者以一个组合成果呈现，先卖结果不卖容量。
